    <p style="text-align:center;margin: 0px;">
     <span style="font-size: 16px;">
      <span lang="ZH-CN" style="margin: 0px;font-family: MingLiU;">
       二十念为一瞬，每个瞬间都有无数的可能性，当无数瞬间连接在一起，流淌起来，形成河流，此时便呈现了时空中变换万端的意象。
      </span>
     </span>
    </p>

     <br/>
    </p>
    <p style="text-align: center;">
     <span style="margin: 0px;color: black;font-family: MingLiU;font-size: 16px;">
      四
     </span>
     <span style="font-size: 16px;">
      <span lang="ZH-CN" style="margin: 0px;color: black;font-family: MingLiU;">
       名舞者用身体互相对话，并与环境对话，与声音对话，与人群对话。
      </span>
     </span>
    </p>
    <p style="text-align: center;">
     <span style="font-size: 16px;">
      <span lang="ZH-CN" style="margin: 0px;color: black;font-family: MingLiU;">
       <br/>
      </span>
     </span>
    </p>
    <p style="text-align: center;">
     <span style="font-size: 16px;">
      <span lang="ZH-CN" style="margin: 0px;color: black;font-family: MingLiU;">
       将身体化为河流，流淌过砖石，流淌过草木，流淌过起伏的山丘，流淌过生和灭，流淌过故事，流淌过无数动人的瞬间。
      </span>
     </span>
     <span style="font-size: 16px;">
      <strong>
       <span lang="ZH-CN" style="margin: 0px;color: black;font-family: MingLiU;">
        <br/>
       </span>
      </strong>
     </span>
    </p>

     <img data-copyright="0" data-ratio="0.708" data-s="300,640" data-type="jpeg" data-w="500" src="/assets/images/8ae539d2d9.jpg" style="width: 100%; max-width: 600px;"/>
     <br/>
    </p>
    <p>
     <span style="font-size: 16px;">
      <span lang="ZH-CN" style="margin: 0px;color: black;font-family: MingLiU;">
       以当代环境舞蹈的艺术方式，留给观众想象空间的前提下，引领观众关注当下，关注流动，引发思考，拨动心弦。
      </span>
     </span>

    <p style="margin: 0px;text-align: center;">
     <strong>
      <span lang="ZH-CN" style="margin: 0px;font-family: MingLiU;">
       郑聿倩
      </span>
     </strong>
     <strong>
      <span lang="EN-US" style="margin: 0px;font-family: MingLiU;">
       <br/>

    <p style="margin: 0px;">
     <span lang="EN-US" style="margin: 0px;font-family: MingLiU;">
      Inch Dance
     </span>
     <span lang="ZH-CN" style="margin: 0px;font-family: MingLiU;">
      创办人，上海即兴艺术节发起人。多媒体艺术家、编舞者、舞者和教师。来自台湾，旅居过美国纽约，目前定居上海。
     </span>
     <span lang="ZH-CN" style="margin: 0px;font-family: MingLiU;">
     </span>
     <span lang="ZH-CN" style="margin: 0px;font-family: MingLiU;">
      她的作品受了中西方的舞蹈和艺术文化的深远影响。
     </span>
     <span lang="ZH-CN" style="margin: 0px;font-family: MingLiU;">
      在大学期间，聿倩结识了接触即兴，并专注于学习创造性肢体开发（
     </span>
     <span lang="EN-US" style="margin: 0px;font-family: MingLiU;">
      creative movement
     </span>
     <span lang="ZH-CN" style="margin: 0px;font-family: MingLiU;">
      ）的教学。大学毕业后，任教于云门舞集舞蹈教室。
     </span>
     <span lang="ZH-CN" style="margin: 0px;font-family: MingLiU;">
      同时间并为古舞团舞者及行政。目前任教于多所机构，分享她多年对于儿童与成人的肢体开发、即兴、接触即兴的心得与感受。
     </span>
     <span lang="EN-US" style="margin: 0px;font-family: MingLiU;">
      2016
     </span>
     <span lang="ZH-CN" style="margin: 0px;font-family: MingLiU;">
      年底成立了寸草舞集
     </span>
     <span lang="EN-US" style="margin: 0px;font-family: MingLiU;">
      (Inch Dance),
     </span>
     <span lang="ZH-CN" style="margin: 0px;font-family: MingLiU;">
      致力于推广现代舞、肢体开发、接触即兴等课程和后现代及舞蹈剧场相关创作演出。
     </span>
     <span lang="EN-US" style="margin: 0px;font-family: MingLiU;">
      2017
     </span>
     <span lang="ZH-CN" style="margin: 0px;font-family: MingLiU;">
      年「上海即兴周」策划制作、表演者。
     </span>
     <strong>
      <span lang="EN-US" style="margin: 0px;font-family: MingLiU;">
       <br/>
      </span>
     </strong>

    <p style="margin: 0px;">
     飞行家身体剧场创办人，上海即兴艺术节发起人。毕业于香港大学整合实效管理专业（研究生）。目前在上海，从事戏剧导演，肢体辅导和艺术教育。创办的飞行家身体剧场，致力于身体剧场的创作和推广。创作和演出的戏剧作品包《对不起，我爱你》、《镜》、《山.水》、《街上的风景》等。作品除了在剧场演出外，也多次与艺术家的艺术作品合作，在余德耀美术馆，M50艺术园区等进行环境戏剧演出，多次参加乌镇戏剧节
    </p>

     </span>
     <span lang="EN-US" style="margin: 0px;font-family: MingLiU;">
      “
     </span>
     <span lang="ZH-CN" style="margin: 0px;font-family: MingLiU;">

      ”
     </span>
     <span lang="ZH-CN" style="margin: 0px;font-family: MingLiU;">
      ，为社区其他艺术家创造机会。大学毕业于加利福尼亚的表演艺术学院，主修编舞和制作。毕业后，她曾参与
     </span>
     <span lang="EN-US" style="margin: 0px;color: rgb(51, 51, 51);font-family: MingLiU;">
      Li Chiao-Ping
     </span>
     <span lang="ZH-CN" style="margin: 0px;font-family: MingLiU;">
      舞团演出，之后威斯康兴大学麦迪逊分校攻读电影和录像硕士，同时间也在布拉格电影学院学习导演。
     </span>
     <span lang="EN-US" style="margin: 0px;font-family: MingLiU;">
      2013
     </span>
     <span lang="ZH-CN" style="margin: 0px;font-family: MingLiU;">
      她联合创办了艺术空间
     </span>
     <span lang="EN-US" style="margin: 0px;color: rgb(51, 51, 51);font-family: MingLiU;">
      Basement 6 Collective
     </span>
     <span lang="ZH-CN" style="margin: 0px;font-family: MingLiU;">
      举办展览和活动。
     </span>
     <span lang="EN-US" style="margin: 0px;font-family: MingLiU;">
      2014
     </span>
     <span lang="ZH-CN" style="margin: 0px;font-family: MingLiU;">
      ，她创办了
     </span>
     <span lang="EN-US" style="margin: 0px;color: rgb(51, 51, 51);font-family: MingLiU;">
      SLATE
     </span>
     <span lang="ZH-CN" style="margin: 0px;font-family: MingLiU;">
      当代舞团，希望能在上海发展当代舞蹈。
     </span>
     <span lang="EN-US" style="margin: 0px;font-family: MingLiU;">
      Anneliese
     </span>
     <span lang="ZH-CN" style="margin: 0px;font-family: MingLiU;">
      的作品曾受邀至上海的多个机构演出包括：上海当代艺术馆，民生美术馆，新时线媒体艺术中心，喜马拉雅艺术中心的上海项目，视觉艺术中心，
     </span>
     <span lang="EN-US" style="margin: 0px;color: rgb(51, 51, 51);font-family: MingLiU;">
      TED X
     </span>
     <span lang="ZH-CN" style="margin: 0px;font-family: MingLiU;">

      K11

     </span>
     <span style="margin: 0px;font-family: MingLiU;">
