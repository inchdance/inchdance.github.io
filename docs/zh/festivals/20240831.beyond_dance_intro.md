         <section style="display: inline-block;border-width: 2px;border-style: solid;border-color: rgba(94, 169, 210, 0.6);padding: 0.1em 0.3em;color: rgb(62, 62, 62);">
          <p style="text-align: justify;text-wrap: wrap;">
           古名伸自1987年从美国返回后，一直作为活跃的编舞家和舞者根基于台湾进行创作。她的作品受到多种西方和东方舞蹈风格的影响，这源于其多元背景的融合发展。
          </p>
          <p style="text-align: justify;text-wrap: wrap;">
           <br/>
          </p>
          <p style="text-align: justify;text-wrap: wrap;">
           自1992年起，古名伸深入参与接触即兴舞蹈，并将其引入台湾。1993年，她创立了自己的舞蹈团体「古舞团」，多年来不断创作、上演新作品并在世界范围内推广即兴舞蹈概念。「古舞团」在纽约、澳大利亚、巴黎、伦敦、中国、韩国、马来西亚、印度尼西亚和日本等地都留下了浓厚的足迹。
          </p>
          <p>
           <br/>
          </p>
          <p style="text-align: justify;text-wrap: wrap;">
           古名伸与中国台湾、香港、日本、澳大利亚、奥地利和美国的许多舞蹈公司和活动合作。她的独舞表演也应邀在美国、伦敦、巴黎、澳大利亚、日本、马来西亚、中国（含香港）巡演。《纽约时报》称其作品“简单而英俊”。
          </p>
          <p>
           <br/>
          </p>
          <p style="text-align: justify;text-wrap: wrap;">
           古名伸受到世界各地许多大学和舞团的邀请，作为客座艺术家在各地进行表演和教学。她在2009年获得了台湾吴三连奖，这是一项终身成就奖，并于2020年获得台湾文艺奖。
          </p>

      <p style="text-wrap: wrap;">
       <span style="font-size: 16px;text-decoration: underline;">
        <strong>
         打开即兴黑盒子 Unfold the Mist
        </strong>
       </span>
      </p>
      <p style="text-wrap: wrap;">
       接触即兴与即兴，是两个看似相近却又可能相去甚远的主题。
      </p>
      <p style="text-wrap: wrap;">
       <br/>
      </p>
      <p style="text-wrap: wrap;">
       接触即兴立意在两个人藉由身体接触，感受到对方传递来的体感，而引发彼此互动的舞蹈行为。这其中包含了对自我身体的认知，对触感的敏感度，以及如何对应的开展。课程将会由浅入深，循序渐进地引导学员从自身个体到与舞伴共舞的过程。
      </p>
      <p style="text-wrap: wrap;">
       <br/>
      </p>
      <p style="text-wrap: wrap;">
       肢体开发以及自由舞蹈的前提，所引发的舞蹈不只在于个人满足的投射，更多关于当下与经验感受的分享。于是本课程也会特别以游戏般的练习，引导即兴的方法
       <strong>
        ，重点包括体感、空间、时间、结构等的要素
       </strong>
       。
      </p>
      <p style="text-wrap: wrap;">
       <br/>
      </p>
      <p style="text-wrap: wrap;">
       <strong>
        期望学员在练习中加深对自我的了解，以及对周遭的关照，并在课程中练习分享。此课程主题面向所有水平学员。
       </strong>
      </p>

      <p style="text-wrap: wrap;">
       <span style="font-size: 16px;text-decoration: underline;">
        <strong>
         整体舞蹈 Total dance
        </strong>
       </span>
      </p>
      <p style="text-wrap: wrap;">
       接触即兴以一个全然平等的身体，运用到所有身体部位，无论是具体的重量、重心，或者轻飘飘接触的一片皮肤，它们都代表了信息的过往。
      </p>
      <p style="text-wrap: wrap;">
       <br/>
      </p>
      <p style="text-wrap: wrap;">
       <strong>
        技巧性的进阶，同时包含了看似无形的敏感度细化，以及在刹那选择的多变。
       </strong>
       如何持续进入未知的领域，是各个环节的相遇整合。再者，当即兴成为表演时，舞者与表演者的身份如何兼容，所有当下的选择即是瞬息万变的决定。
       <br/>
      </p>
      <p style="text-wrap: wrap;">
       <br/>
      </p>
      <p style="text-wrap: wrap;">
       <strong>
        本次进阶班的课程将包含「接触即兴进阶课程」，以及「表演专题」两个部分。
       </strong>
       进阶课程内容包含
       <strong>
        如何在动与静之间找到最不预期的缝隙进行挑战，以及如何在小面积的重心上得到稳定。
       </strong>
       表演专题目的在于
       <strong>
        提高舞者对当下处境的全面关照，以及如何对观众的凝视采取对应等的议题。
       </strong>
      </p>

          <p style="text-wrap: wrap;">
           <strong>
            马才和 Victor Ma
           </strong>
          </p>
          <p style="text-wrap: wrap;">
           马才和于1995年创立舞团「多空間」，并担任艺术总监。为香港演艺学院舞蹈学院及戏剧学院毕业生，曾为城市当代舞蹈团及香港芭蕾舞团之全职舞者。1996年获亚洲文化协会利希慎奖学金，翌年前往美国考察当代舞蹈及剧场；2001年凭电影《情色地圖》获台湾金马奖提名最佳男配角。
          </p>
          <p style="text-wrap: wrap;">
           <br/>
          </p>
          <p style="text-wrap: wrap;">
           2002年获香港艺术发展局列斯大学志奋领奖学金前往英国修读表演研究硕士课程，曾为多个香港及国际艺术团体担任编舞及形体设计，教学、表演及创作，足迹遍及台湾、中国、南韩、印度、美国、澳洲、德国、挪威、丹麦、波兰、津巴布韦，创作超过六十多部作品。
          </p>
          <p style="text-wrap: wrap;">
           <br/>
          </p>
          <p style="text-wrap: wrap;">
           重要作品包括《冇關係》、《不是雙人房》、《昏迷I及II》、《「舞」可能﹗？壹至柒》、《緣舞場1–78》、《呼吸I、II及III》、《身體、空間與身份I—V》、《馬才和的舞蹈展覽I及II》、《反反覆覆》、《突然之間》、《追趕跑跳…轉》、《房一房二房叉防》、《門》、《渾舞》、《球賽》、《「你/理」想舞蹈 ！？》及《球賽 - 奔分世界》等。
          </p>
          <p style="text-wrap: wrap;">
           <br/>
          </p>
          <p style="text-wrap: wrap;">
           由 2009 年开始担任 i-舞蹈節（香港）之艺术总监及策划人。马氏亦获香港艺术发展局颁发「2016香港艺术家奖」「艺术家年奖」（舞蹈）。2019年起举办「有机形体及转化训练」一年制舞蹈与表演艺术证书课程，任课程总设计及导师

          <p style="text-align: justify;text-wrap: wrap;">
           「多空間」创办人之一，香港演艺学院舞蹈系首届毕业生。曾为香港芭蕾舞团及城市当代舞蹈团为全职舞者。1996年严氏获亚洲文化协会利希慎奖学金，前往美国考察当代舞蹈及剧场，2000年应非洲津巴布韦哈拉雷国际艺术节之邀前往非洲并为当地创作环境舞蹈《舞滙杂碎》，同年九月获挪威 End of Millenium Festival 及卑尔根十月舞蹈节邀请前往参加艺术节之演出（2002），并担任SUF之驻场艺术家。
          </p>
          <p>
           <br/>
          </p>
          <p style="text-align: justify;text-wrap: wrap;">
           严氏亦曾应邀到德国德勒斯登第十届Tanzwoche 舞蹈节（2001）、韩国艺穗节（2002）、印度加尔各答 Interface 艺术节（2004）、澳洲墨尔本艺穗节（2005）、中国北京大山子国际艺术节（2005）、深圳交叉：OCAT 当代舞蹈剧场演出季（2009）、波兰国际当代舞蹈会议及表演节（2008及2010）、i-Dance（台北）2011及2019、i-Dance（韩国）2012、2016及2018、i-Dance（日本）2013、2015、2017及2023等地进行表演及交流。严氏之教学、表演及创作足迹遍及欧美亚非等不同国家。
          </p>
          <p>
           <br/>
          </p>
          <p style="text-align: justify;text-wrap: wrap;">
           2010年至现在，受邀至香港中文大学社工系担任客席导师。自2009年开始为 i-舞蹈節（香港）监制，现为「多空間」外展及教育总监。2019年起，任「有机形体及转化训练」一年制舞蹈与表演艺术证书课程之课程设计及导师。

         有机形体及转化训练

      <p style="text-wrap: wrap;">
       <span style="font-size: 16px;">
        <strong>
         Organic Movement and Transformation Training (OMOTT)
        </strong>
       </span>
      </p>
      <p style="text-wrap: wrap;">
       <br/>
      </p>
      <p style="text-wrap: wrap;">
       OMOTT由马才和研发及整理，并由严明然协助发展，课程从聆听和探索身体开始，继而透过观察及想像发展肢体动作并累积舞蹈词汇。OMTT之训练方式主要是鼓励学员融汇生活、舞蹈和不同艺术媒体，引导参与者开拓身体潜能，发展肢体动作、延伸表演幅度继而进行创作即兴及表演。
