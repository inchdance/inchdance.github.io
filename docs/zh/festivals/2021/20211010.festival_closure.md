       <span style="caret-color: rgb(0, 0, 0);text-align: center;color: rgb(0, 0, 0);font-family: Optima-Regular, PingFangTC-light;font-size: 15px;letter-spacing: 2px;background-color: rgb(255, 255, 255);">
        10月7日，由星署文化、寸草舞集联合主办，上服德必徐家汇WE''协办的“2021年第四届上海即兴艺术节”在画家街圆满落幕。
        <br/>
       </span>
      </p>
      <p style="white-space: normal;margin: 0px;padding: 0px;box-sizing: border-box;font-size: 14px;font-family: PingFangTC-ultralight;letter-spacing: 0px;line-height: 2;font-style: normal;font-weight: 400;text-align: justify;">
       <span style="caret-color: rgb(0, 0, 0);text-align: center;color: rgb(0, 0, 0);font-family: Optima-Regular, PingFangTC-light;font-size: 15px;letter-spacing: 2px;background-color: rgb(255, 255, 255);">
        <br/>
       </span>
      </p>
      <p style="white-space: normal;margin: 0px;padding: 0px;box-sizing: border-box;font-size: 14px;font-family: PingFangTC-ultralight;letter-spacing: 0px;line-height: 2;font-style: normal;font-weight: 400;text-align: justify;">
       <span style="caret-color: rgb(0, 0, 0);text-align: center;color: rgb(0, 0, 0);font-family: Optima-Regular, PingFangTC-light;font-size: 15px;letter-spacing: 2px;background-color: rgb(255, 255, 255);">
        以”与光牵手（LET THERE BE LIGHT）”为主题，本届上海即兴艺术节历时7天（10月01日-10月07日），共计有36位来自全球的优秀艺术家、导师及艺术团队参演，期间一共为大家带来了17场不同领域的演出剧目，8场跨领域艺术家工作坊，3场跨界国际论坛（线上+线下），2场即兴大party。累计3W+位学员、观众（线上+线上）参与其中，在国庆期间为大家带来了无与伦比的艺术观赏和参与体验。
       </span>
      </p>
      <p style="white-space: normal;margin: 0px;padding: 0px;box-sizing: border-box;font-size: 14px;font-family: PingFangTC-ultralight;letter-spacing: 0px;line-height: 2;font-style: normal;font-weight: 400;text-align: justify;">
       <br style="box-sizing: border-box;"/>
      </p>
      <p style="white-space: normal;margin: 0px;padding: 0px;box-sizing: border-box;font-size: 14px;font-family: PingFangTC-ultralight;letter-spacing: 0px;line-height: 2;font-style: normal;font-weight: 400;text-align: justify;">
       <span style="caret-color: rgb(0, 0, 0);text-align: center;color: rgb(0, 0, 0);font-family: Optima-Regular, PingFangTC-light;font-size: 15px;letter-spacing: 2px;background-color: rgb(255, 255, 255);">
        本届上海即兴艺术节以身体为出发，跨界联合了诸多领域，如沉浸式戏剧、脑功能科学和身体机能、接触即兴、行为影像、绘画与新媒体表演、多维度设计与身体、不同门类即兴合作、即兴音乐剧、音乐手偶剧、身体影像、互动新媒体、即兴舞蹈等
       </span>
       <span style="caret-color: rgb(0, 0, 0);text-align: center;color: rgb(0, 0, 0);font-family: Optima-Regular, PingFangTC-light;font-size: 15px;letter-spacing: 2px;background-color: rgb(255, 255, 255);">
        。
        <strong>
         其中诸多作品的呈现都是艺术家根据画家街独特的街区环境和文化氛围即兴发生和限定呈现的。
        </strong>
       </span>

        画家街所在园区门前的文定路，得名于明朝科学家徐光启谥号文定。近现代时期，这里是中国近代美术及工艺美术的发源地——土山湾。这里是上海中西文化交融最早、最充分的地区之一，也是闻名遐迩的海派文化发源地。
        <strong>
         上海即兴艺术节通过与画家街现场环境的巧妙融合，为大家带了一场精彩的公共艺术展。
