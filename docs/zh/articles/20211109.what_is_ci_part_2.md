    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="color: rgb(132, 151, 176);font-style: italic;font-size: 12px;">
      “达菲先生住在离他身体有点远的地方。”
     </span>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="color: rgb(132, 151, 176);font-style: italic;font-size: 12px;">
      -詹姆斯.乔伊斯
     </span>
    </p>
    <p style="text-align: right;">
     <br/>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="color: black;font-size: 14px;">
      有时候，我们也住在离自己身体有点远的地方。不是吗？
     </span>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="color: black;font-size: 14px;">
      CI到底是什么？这是一个非常基础又非常重要的问题。随着玩的进程，这个问题会反复冒出来，它帮助我们越来越深入到问题的核心。我们看看关于这点，作者还有CI的创始者们，他们是怎么说的。
     </span>
    </p>
    <p style="text-align: right;">
     <br/>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="font-size: 16px;">
      <span style="font-family: Cambria;color: rgb(64, 64, 64);font-weight: bold;">
       CI
      </span>
      <span style="font-family: 微软雅黑;color: rgb(64, 64, 64);font-weight: bold;">
       是什么样子的？
      </span>
     </span>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="font-size:21px;font-family:微软雅黑;color:#404040;font-weight:bold;">
      <br/>
     </span>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="font-size: 14px;">
      <span style="font-family: 宋体;color: black;">
       如果你没有参加
      </span>
      <span style="font-family: Calibri;color: black;">
       CI
      </span>
      <span style="font-family: 宋体;color: black;">
       的话，那它看起来可能是这样的：
      </span>
     </span>
    </p>
    <p style="text-align: left;">
     <span style="font-size: 24px;">
      <span style="color: rgb(64, 64, 64);font-size: 43px;font-style: italic;font-weight: 700;text-align: left;">
      </span>
      <span style="font-style: italic;font-weight: 700;text-align: left;color: rgb(0, 0, 0);font-size: 36px;">
       “
      </span>
     </span>
     <br/>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="color: rgb(132, 151, 176);font-style: italic;font-size: 12px;">
      两个舞者从不同的地方出发，占据同一个空间。光着脚，穿着棉质疏松的衣服。一个人的手肘擦过另一个人的腹部，腹部随之扩展，使得手肘打开，手臂向外伸展。这个动作引出了下一个动作，两个身体相互沿着可用的平面滚动起来——背部，肩膀、大腿——其间对抗、柔顺、惯性、重力、压力不断变化。
     </span>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <br/>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="color: rgb(132, 151, 176);font-style: italic;font-size: 12px;">
      舞蹈可能慢也可能快，可能表现出高超的运动机能，也可能非常柔和。这样就开始了一个双人的接触即兴，动作中体现出一种偶然性和开放性的新鲜组合，一个与搭档之间的、依赖于身体共同动作的即兴舞蹈。除了对接触点的动态变化的觉知之外，没有其它预设。
     </span>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="font-size:19px;color:#8497B0;font-style:italic;">
      <br/>
     </span>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="font-size: 16px;">
      <span style="font-family: 微软雅黑;color: rgb(64, 64, 64);font-weight: bold;">
       到底什么是
      </span>
      <span style="font-family: Cambria;color: rgb(64, 64, 64);font-weight: bold;">
       CI
      </span>
      <span style="font-family: 微软雅黑;color: rgb(64, 64, 64);font-weight: bold;">
       ，它的定义是什么？
      </span>
     </span>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <br/>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="font-size: 14px;color: black;">
      关于这一点，Paxton，也就是CI的创始人是这样说的。很有意思的观点，值得好好品味。
     </span>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="font-size:43px;color:#404040;font-weight:bold;font-style:italic;">
      <span style="color: rgb(0, 0, 0);font-size: 36px;font-style: italic;font-weight: 700;text-align: left;">
       “
      </span>
     </span>
    </p>
    <p style="text-align: right;direction: ltr;unicode-bidi: embed;">
     <span style="font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;font-size: 12px;">
      当我们开始的时候，我们不知道自己在做什么，
      <br/>
     </span>
    </p>
    <p style="text-align: right;direction: ltr;unicode-bidi: embed;">
     <span style="font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;font-size: 12px;">
      也不知道它会去向哪里。我们必须留出空间，
     </span>
    </p>
    <p style="text-align: right;direction: ltr;unicode-bidi: embed;">
     <span style="font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;font-size: 12px;">
      这样它才能自然发展，而不是我们要让它去哪。
     </span>
    </p>
    <p style="text-align: right;direction: ltr;unicode-bidi: embed;">
     <span style="font-size: 12px;">
      <span style="font-family: Calibri;color: rgb(132, 151, 176);font-style: italic;">
       CI
      </span>
      <span style="font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;">
       基本上是两个人各自跳舞，同时保持在接触之中，
      </span>
     </span>
    </p>
    <p style="text-align: right;direction: ltr;unicode-bidi: embed;">
     <span style="font-size: 12px;">
      <span style="font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;">
       在他们之间创造出一个第三者。这个第三者就是
      </span>
      <span style="font-family: Calibri;color: rgb(132, 151, 176);font-style: italic;">
       CI
      </span>
      <span style="font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;">
       。
      </span>
     </span>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="font-size:19px;font-family:宋体;color:#8497B0;font-style:italic;">
      <br/>
     </span>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="color: rgb(64, 64, 64);font-size: 14px;">
      从这个描述中，CI似乎更多的是一个独立存在的、自身会自由演化的东西，它似乎有自己的生命，我们并不能定义它。它随着遇到的人自然发展和转化。然而无论它是什么，显然它与控制无关。
     </span>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="color: rgb(64, 64, 64);font-size: 14px;">
      <br/>
     </span>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="color: rgb(64, 64, 64);font-size: 43px;font-style: italic;font-weight: 700;">
     </span>
     <span style="font-style: italic;font-weight: 700;color: rgb(0, 0, 0);font-size: 36px;">
      “
     </span>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="font-size: 12px;">
      <span style="font-family: Calibri;color: rgb(132, 151, 176);font-style: italic;">
       Paxton
      </span>
      <span style="font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;">
       的学生，还有很多纽约的舞者，
      </span>
      <br/>
     </span>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="font-size: 12px;">
      <span style="font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;">
       尤其是
      </span>
      <span style="font-family: Calibri;color: rgb(132, 151, 176);font-style: italic;">
       Smith
      </span>
      <span style="font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;">
       ，她花了很多时间研究练习
      </span>
     </span>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="font-size: 12px;">
      <span style="font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;">
       和表演的录像，他们帮助
      </span>
      <span style="font-family: Calibri;color: rgb(132, 151, 176);font-style: italic;">
       Paxton
      </span>
      <span style="font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;">
       深化
      </span>
     </span>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;font-size: 12px;">
      他的理解，并且为这种舞蹈找到表达的语言。
     </span>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <br/>
    </p>
    <p style="text-align: right;direction: ltr;unicode-bidi: embed;">

     </span>

    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="color: rgb(64, 64, 64);font-size: 14px;">
      从这段可以看到，从一开始CI就是一种对话。在CI初期，Nancy Stark Smith是一个非常重要的参与者，最开始的时候，Paxton的活动中没有女性，观看了他们表演的Nancy对这种形式产生了很大兴趣，她主动跟Paxton要求参与进来。后来，她成为了Paxton的合作伙伴，共同创造了CI，并且长期担任教授CI的老师，她还主导创建了一本CI的刊物（Contact Quarterly），对CI的深化和传播起到了非常重要的作用。
     </span>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <br/>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="color: rgb(64, 64, 64);font-size: 14px;">
      这个短短的轶事似乎也是一个隐喻，CI是这样发展为今天这个样子的。开始时Paxton对CI更多是一种直觉的投入，并没有太多理性化的思考，Nancy的加入无疑促进了直觉与理性的互动。如果说当时Paxton作为舞者直觉地创造了CI，Nancy和其他舞者则是作为观者给CI注入了更多意识化的东西。无意识与意识的交汇，帮助CI从混沌中逐渐清晰，这意义非凡。
     </span>
    </p>
    <p style="text-align: left;direction: ltr;unicode-bidi: embed;">
     <span style="font-size: 10px;font-family: nyt-imperial;color: rgb(64, 64, 64);">
      <br/>
     </span>
     <br/>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="font-size: 16px;">
      <span style="font-family: Cambria;color: rgb(64, 64, 64);font-weight: bold;">
       CI
      </span>
      <span style="font-family: 微软雅黑;color: rgb(64, 64, 64);font-weight: bold;">
       是谁的？
      </span>
     </span>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="font-size: 16px;font-family: 微软雅黑;color: rgb(64, 64, 64);font-weight: bold;">
      <br/>
     </span>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="color: black;font-size: 14px;">
      Paxton是CI的创始人，然而从上面的定义就看 出他对CI的态度，他也并没有说CI是他的。
     </span>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="color: black;font-size: 14px;">
      <br/>
     </span>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="font-size:43px;color:#404040;font-weight:bold;font-style:italic;">
      <span style="color: rgb(64, 64, 64);font-style: italic;font-weight: 700;text-align: left;">
      </span>
      <span style="font-style: italic;font-weight: 700;text-align: left;color: rgb(0, 0, 0);font-size: 36px;">
       “
      </span>
     </span>
    </p>
    <p style="text-align: right;direction: ltr;unicode-bidi: embed;">
     <span style="font-size:19px;font-family:Calibri;color:#8497B0;font-style:italic;">
     </span>
     <span style="font-size: 12px;">
      <span style="font-family: Calibri;color: rgb(132, 151, 176);font-style: italic;">
       Paxton
      </span>
      <span style="font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;">
       对于保持控制兴趣不大，他更想看这种形式本身会
      </span>
     </span>
    </p>
    <p style="text-align: right;direction: ltr;unicode-bidi: embed;">
     <span style="font-size: 12px;">
      <span style="font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;">
       如
      </span>
      <span style="color: rgb(132, 151, 176);font-family: 宋体;font-style: italic;caret-color: transparent;">
       何发展。他考虑过版权的问题，主要是因为听说到一些
      </span>
     </span>
    </p>
    <p style="text-align: right;direction: ltr;unicode-bidi: embed;">
     <span style="font-size: 12px;">
      <span style="color: rgb(132, 151, 176);font-family: 宋体;font-style: italic;caret-color: transparent;">
       人
      </span>
      <span style="font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;">
       在这种活动中受伤。参与者还没有学有关敏感性、接触、
      </span>
     </span>
    </p>
    <p style="text-align: right;direction: ltr;unicode-bidi: embed;">
     <span style="font-size: 12px;color: rgb(132, 151, 176);font-family: 宋体;font-style: italic;caret-color: transparent;">
      重力等基础，就开始模仿这种活动，因此导致受伤。他因此
     </span>
    </p>
    <p style="text-align: right;direction: ltr;unicode-bidi: embed;">
     <span style="font-size: 12px;color: rgb(132, 151, 176);font-family: 宋体;font-style: italic;caret-color: transparent;">
      想申请版权，以保证这种舞蹈的完整性，避免有人鲁莽行事。
     </span>
    </p>
    <p style="text-align: right;direction: ltr;unicode-bidi: embed;">
     <span style="font-size: 12px;">
      <span style="color: rgb(132, 151, 176);font-family: 宋体;font-style: italic;caret-color: transparent;">
       但最终他决定不这样做，他更期望一种持续
      </span>
      <span style="caret-color: transparent;font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;">
       的对话。结果就是，
      </span>
     </span>
    </p>
    <p style="text-align: right;direction: ltr;unicode-bidi: embed;">
     <span style="font-size: 12px;">
      <span style="caret-color: transparent;font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;">
       不需要获得
      </span>
      <span style="caret-color: transparent;font-family: Calibri;color: rgb(132, 151, 176);font-style: italic;">
       Paxton
      </span>
      <span style="caret-color: transparent;font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;">
       的授权，学过这
      </span>
      <span style="color: rgb(132, 151, 176);font-family: 宋体;font-style: italic;">
       种舞蹈的人就可以表演，可以
      </span>
     </span>
    </p>
    <p style="text-align: right;direction: ltr;unicode-bidi: embed;">
     <span style="font-size: 12px;color: rgb(132, 151, 176);font-family: 宋体;font-style: italic;">
      将其融入自己的编舞之中，可以教别人，即使是一种它的变体，
     </span>
    </p>
    <p style="text-align: right;direction: ltr;unicode-bidi: embed;">
     <span style="font-size: 12px;color: rgb(132, 151, 176);font-family: 宋体;font-style: italic;">
      舞者可以把它纳入到自己的活动之中。
     </span>
    </p>
    <p style="text-align: right;direction: ltr;unicode-bidi: embed;">
     <br/>
    </p>
    <p style="text-align: right;direction: ltr;unicode-bidi: embed;">
     <br/>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="color: black;font-size: 14px;">
      可以看出来，CI非常自由，在保证安全的前提下，它可以与各种形式融合。
     </span>
    </p>
    <p style="text-align: right;">
     <br/>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="font-size: 16px;">
      <span style="font-family: Cambria;color: rgb(64, 64, 64);font-weight: bold;">
       Paxton
      </span>
      <span style="font-family: 微软雅黑;color: rgb(64, 64, 64);font-weight: bold;">
       关于
      </span>
      <span style="font-family: Cambria;color: rgb(64, 64, 64);font-weight: bold;">
       CI
      </span>
      <span style="font-family: 微软雅黑;color: rgb(64, 64, 64);font-weight: bold;">
       的六个基本元素
      </span>
     </span>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="font-size:21px;font-family:微软雅黑;color:#404040;font-weight:bold;">
      <br/>
     </span>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="color: black;font-size: 14px;">
      CI的开放性无疑很有价值，但同时也带来一些问题，如果CI如此开放，那它的本质是什么？什么是最重要的部分呢？
     </span>
    </p>

      </span>
      <span style="font-style: italic;font-weight: 700;text-align: left;color: rgb(0, 0, 0);font-size: 36px;">
       “
      </span>
     </span>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="font-size: 19px;font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;">
     </span>
     <span style="font-size: 12px;">
      <span style="font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;">
       为了保持一致，但又不至于封闭，
      </span>
      <span style="font-family: Calibri;color: rgb(132, 151, 176);font-style: italic;">
       Paxton
      </span>
      <span style="font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;">
       在
      </span>
      <span style="font-family: Calibri;color: rgb(132, 151, 176);font-style: italic;">
       1975
      </span>
      <span style="font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;">
       年的一篇
      </span>
     </span>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="font-size: 12px;">
      <span style="font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;">
       文中谈到，
      </span>
      <span style="font-family: Calibri;color: rgb(132, 151, 176);font-style: italic;">
       CI
      </span>
      <span style="font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;">
       作为一个不断发展的进程，包涵
      </span>
      <span style="font-family: Calibri;color: rgb(132, 151, 176);font-style: italic;">
       6
      </span>
      <span style="font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;">
       个基本元
      </span>
     </span>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;font-size: 12px;">
      素：态度，对时机的感觉，空间导向，搭档导向，扩展
     </span>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;font-size: 12px;">
      对周边环境的视野，肌肉发展（包括保持中心，拉伸，
     </span>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;font-size: 12px;">
      承受重量，增加关节动作）。他说：‘双人中的每一
     </span>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;font-size: 12px;">
      方自由即兴动作，其目标是找到一种最省力的方式来
     </span>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;font-size: 12px;">
      移动自己的身体。只有在肌肉放松地伸展、四肢张开
     </span>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;font-size: 12px;">
      时，这种方式才能被感知到。
     </span>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;font-size: 14px;">
      <br/>
     </span>
    </p>
    <p style="text-align: right;">
     <br/>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="font-size: 16px;">
      <span style="font-family: 微软雅黑;color: rgb(64, 64, 64);font-weight: bold;">
       谁可以玩
      </span>
      <span style="font-family: Cambria;color: rgb(64, 64, 64);font-weight: bold;">
       CI
      </span>
     </span>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="font-size:21px;font-family:Cambria;color:#404040;font-weight:bold;">
      <br/>
     </span>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="color: black;font-size: 14px;">
      这无疑是一个非常重要的问题。作为一种后现代的舞蹈形式，CI打破了专业舞者与普通人之间的藩篱，接触即兴中，任何自然的动作都成为了舞蹈的一部分，走路也成为了舞蹈。如果走路也是舞蹈，那就不能说，你比我走得更专业了。
     </span>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="font-size:19px;color:black;">
      <br/>
     </span>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="color: rgb(64, 64, 64);font-size: 43px;font-style: italic;font-weight: 700;text-align: left;">
      <span style="color: rgb(64, 64, 64);font-style: italic;font-weight: 700;text-align: left;">
      </span>
      <span style="font-style: italic;font-weight: 700;text-align: left;color: rgb(0, 0, 0);font-size: 36px;">
       “
      </span>
     </span>
    </p>
    <p style="text-align: justify;direction: ltr;unicode-bidi: embed;">
     <span style="font-size:19px;font-family:宋体;color:#8497B0;font-style:italic;">
     </span>
     <span style="font-size: 14px;font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;">
     </span>
     <span style="font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;font-size: 12px;">
      非常有意义的是，非职业舞者也参与到接触即兴中来了，
     </span>
    </p>
    <p style="text-align: justify;direction: ltr;unicode-bidi: embed;">
     <span style="font-size: 12px;">
      <span style="font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;">
       这部分是因为
      </span>
      <span style="font-family: Calibri;color: rgb(132, 151, 176);font-style: italic;">
       Paxton
      </span>
      <span style="font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;">
       的民主思想。有经验的舞者与新人
      </span>
     </span>
    </p>
    <p style="text-align: justify;direction: ltr;unicode-bidi: embed;">
     <span style="font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;font-size: 12px;">
      一起共舞，与软件工程师一起共舞，与木匠一起工作，
     </span>
    </p>
    <p style="text-align: justify;direction: ltr;unicode-bidi: embed;">
     <span style="font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;font-size: 12px;">
      与咨询师们一起共舞。尽管很多舞蹈只有那些苗条优美
     </span>
    </p>
    <p style="text-align: justify;direction: ltr;unicode-bidi: embed;">
     <span style="font-size: 12px;">
      <span style="font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;">
       的身体才能参与，
      </span>
      <span style="font-family: Calibri;color: rgb(132, 151, 176);font-style: italic;">
       CI
      </span>
      <span style="font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;">
       欢迎所有类型的人参加
      </span>
      <span style="font-family: Calibri;color: rgb(132, 151, 176);font-style: italic;">
       ——
      </span>
      <span style="font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;">
       庞大的、
      </span>
     </span>
    </p>
    <p style="text-align: justify;direction: ltr;unicode-bidi: embed;">
     <span style="font-size: 12px;">
      <span style="font-family: 宋体;color: rgb(132, 151, 176);font-style: italic;">
       娇小的、不同能力者、年迈者。没有人被拒之门外
      </span>
      <span style="font-family: 宋体;color: rgb(132, 151, 176);">
       。
      </span>
     </span>
    </p>
    <p style="text-align: justify;direction: ltr;unicode-bidi: embed;">
     <span style="font-size:19px;font-family:宋体;color:#8497B0;">
      <br/>
     </span>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="color: black;font-size: 14px;">
      鲍德里亚说：“艺术应该是对生命的肯定，而非试图带来某种秩序……它只是一种唤醒，唤醒我们正在过着的生命。如果我们不让自己的思想和欲望阻碍它的进程，我们会发现生命本身非常卓越、让人敬畏。”
     </span>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="color: black;font-size: 14px;">
     </span>
    </p>
    <p style="text-align:left;direction:ltr;unicode-bidi:embed;">
     <span style="color: black;font-size: 14px;">
      艺术并不应该远离生活，而应在生活之中。作为一种艺术形式的接触即兴是一种普通人可以参与的艺术，是一种对生命的唤醒和肯定。
     </span>
