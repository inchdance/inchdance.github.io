       <span style="max-width: 100%;font-size: 18px;font-family: 宋体;color: rgb(0, 77, 230);box-sizing: border-box !important;word-wrap: break-word !important;">
        <img class="" data-copyright="0" data-ratio="0.7453125" data-s="300,640" data-type="jpeg" data-w="1280" src="/assets/images/eeea67a0a4.jpg" style="white-space: normal;"/>
       </span>
      </strong>
     </span>
    </p>
    <p style="margin-bottom: 0.1px;max-width: 100%;min-height: 1em;widows: 2;box-sizing: border-box !important;word-wrap: break-word !important;">
     <span style="max-width: 100%;font-family: Helvetica, sans-serif;color: black;font-size: 14px;box-sizing: border-box !important;word-wrap: break-word !important;">
     </span>
    </p>
    <p style="margin-bottom: 0.1px;max-width: 100%;min-height: 1em;widows: 2;box-sizing: border-box !important;word-wrap: break-word !important;">
     <span style="font-size: 14px;">
      <span style="font-size: 14px;max-width: 100%;box-sizing: border-box !important;word-wrap: break-word !important;">
       <strong style="max-width: 100%;box-sizing: border-box !important;word-wrap: break-word !important;">
        <span style="font-size: 14px;max-width: 100%;font-family: Helvetica, sans-serif;color: black;box-sizing: border-box !important;word-wrap: break-word !important;">
         Echo:
        </span>
       </strong>
       <span style="font-size: 14px;max-width: 100%;font-family: 宋体;color: black;">
        想到我刚才要说什么的事了。因为到了最后，其实我蛮累的，昨天因为一开始就很积极的，要做一些上到别人身体上啊，翻滚啊的
       </span>
      </span>
      <span style="font-size: 14px;font-family: 宋体;color: black;max-width: 100%;box-sizing: border-box !important;word-wrap: break-word !important;">
       动
      </span>
     </span>
     <span style="font-family: 宋体;color: black;max-width: 100%;font-size: 14px;box-sizing: border-box !important;word-wrap: break-word !important;">
      作，也没有充分热身好，所以就会扭到腰，而且会很累。一开始跳的那些都是需要用力的，绷紧的那种。（感想：太用力容易累，而且也容易受伤，在哪都一样，不是吗？）
     </span>
    </p>
    <p style="margin-bottom: 0.1px;max-width: 100%;min-height: 1em;widows: 2;box-sizing: border-box !important;word-wrap: break-word !important;">
     <span style="max-width: 100%;font-family: Helvetica, sans-serif;color: black;font-size: 14px;box-sizing: border-box !important;word-wrap: break-word !important;">
     </span>
    </p>
    <p style="margin-bottom: 0.1px;max-width: 100%;min-height: 1em;widows: 2;box-sizing: border-box !important;word-wrap: break-word !important;">
     <span style="max-width: 100%;font-size: 14px;box-sizing: border-box !important;word-wrap: break-word !important;">
      <span style="font-size: 14px;max-width: 100%;font-family: 宋体;color: black;">
       但是最后因为我本身已经没有太多力气了，所以基本上那个动作都是随性的，就是跟着能量走的，不是我刻意主动要做出什么动作，或者是跳上你的肩上这样，而是到了那个点，就自己上去了，不费力的那种感觉。
      </span>
      <strong style="max-width: 100%;box-sizing: border-box !important;word-wrap: break-word !important;">
       <span style="font-size: 14px;max-width: 100%;font-family: 宋体;color: rgb(0, 77, 230);box-sizing: border-box !important;word-wrap: break-word !important;">
        我觉得这个
       </span>
      </strong>
      <strong style="max-width: 100%;box-sizing: border-box !important;word-wrap: break-word !important;">
       <span style="font-size: 14px;max-width: 100%;font-family: 宋体;color: rgb(0, 77, 230);box-sizing: border-box !important;word-wrap: break-word !important;">
        CI的本质，真的就是毫不费力，要找到那个点，是不费力的，所以别人看起来就非常轻松自然，像水一样。
       </span>
      </strong>
     </span>
    </p>
    <p style="margin-bottom: 0.1px;max-width: 100%;min-height: 1em;widows: 2;box-sizing: border-box !important;word-wrap: break-word !important;">
     <span style="max-width: 100%;font-family: Helvetica, sans-serif;color: black;font-size: 14px;box-sizing: border-box !important;word-wrap: break-word !important;">
     </span>
    </p>
    <p style="margin-bottom: 0.1px;max-width: 100%;min-height: 1em;widows: 2;box-sizing: border-box !important;word-wrap: break-word !important;">
     <span style="font-size: 14px;">
      <span style="font-size: 14px;max-width: 100%;box-sizing: border-box !important;word-wrap: break-word !important;">
       <strong style="max-width: 100%;box-sizing: border-box !important;word-wrap: break-word !important;">
        <span style="font-size: 14px;max-width: 100%;font-family: 宋体;color: black;box-sizing: border-box !important;word-wrap: break-word !important;">
         勇者
        </span>
       </strong>
       <strong style="max-width: 100%;box-sizing: border-box !important;word-wrap: break-word !important;">
        <span style="font-size: 14px;max-width: 100%;font-family: Helvetica, sans-serif;color: black;box-sizing: border-box !important;word-wrap: break-word !important;">
         :
        </span>
       </strong>
       <span style="font-size: 14px;max-width: 100%;font-family: 宋体;color: black;">
        对呀，如果要刻意去做，设想着要做什么的话，那就不是一种自然的状态了，也很难达到最后我们跳的那种感觉。因为一刻意，心就离开当下了，身心就分离了。跟当下脱节了，所以就不能达到一种比
       </span>
      </span>
      <span style="font-size: 14px;font-family: 宋体;color: black;max-width: 100%;box-sizing: border-box !important;word-wrap: break-word !important;">
       较好的状态。（感想：又觉得这太像人际关系中发生的事情了……）
      </span>
     </span>
    </p>
    <p style="margin-bottom: 0.1px;max-width: 100%;min-height: 1em;widows: 2;box-sizing: border-box !important;word-wrap: break-word !important;">

      </span>
      <strong style="max-width: 100%;box-sizing: border-box !important;word-wrap: break-word !important;">
       <span style="font-size: 14px;max-width: 100%;font-family: 宋体;color: rgb(0, 77, 230);box-sizing: border-box !important;word-wrap: break-word !important;">

       </span>
      </strong>
      <span style="font-size: 14px;max-width: 100%;font-family: 宋体;color: black;">
       ，对自己，对别人来说都是一种赏心悦目。
      </span>

       <span style="font-size: 14px;max-width: 100%;font-family: 宋体;color: rgb(0, 77, 230);box-sizing: border-box !important;word-wrap: break-word !important;">
        那是自己身心合一，跟搭档也比较契合的一种状态。美好的状态。
       </span>
      </strong>
     </span>
