    体验身体的合奏｜什么是潜动谱UnderScore
   </h1>
   <div class="rich_media_content js_underline_content defaultNoSetting" id="js_content" style=" ">
    <p style="margin-bottom: 0px;">
     <br/>
    </p>
    <section style="margin-left: 16px;margin-right: 16px;">
     <strong>
      <span style="font-size: 16px;">
       潜动谱
      </span>
     </strong>
     <span style="font-size: 14px;">
      （UnderScore）是Nancy Stark Smith从1990年代开始逐渐发展出来的一个练习和研究舞蹈即兴的框架，它引导参与者从个人的深化/放松和对于重力的感知开始，扩展到更为广阔的练习层面，让人们更自在地在空间中跳舞，在即兴中整合各种动觉的组合。它容纳所有范围的能量与肢体表达，包含多样的形式和变化状态。这种练习既熟悉，又不可预测。
     </span>
     <o:p>
     </o:p>
    </section>
    <section style="margin-left: 16px;margin-right: 16px;">
     <span style="font-size: 14px;">
      <br/>
     </span>
    </section>
    <section style="margin-left: 16px;margin-right: 16px;">
     <span style="font-size: 14px;">
      潜动谱是一个舞谱，一些朋友不了解谱（Score）是什么意思，我们可以从乐谱的角度来获得一点理解，乐谱用符号来记录音乐的方法，有了乐谱，人们就可以将一首音乐重新演奏或者唱出来。
      <strong>
       舞谱
      </strong>
      与之类似，是用符号或文字来记录或者描述一段舞蹈。不过一般来说，即兴中的舞谱不像乐谱那么精确，它通常只是提供一个结构框架和核心要素，其中有很多舞者可以自由发挥的部分。
     </span>
    </section>
    <section style="margin-left: 16px;margin-right: 16px;">
     <span style="font-size: 14px;">
      <br/>
     </span>
    </section>
    <section style="margin-left: 16px;margin-right: 16px;">
     <span style="font-size: 14px;">
      <img class="rich_pages wxw-img" data-backh="352" data-backw="558" data-before-oversubscription-url="http://mmbiz.qpic.cn/mmbiz_jpg/TrW9NKr3777ibcDzjo9N6SlHXUnvpicXxo2LJ6QsXzmKib2KjeY5tZcGJlC5ibRjG9ZmaokLr0Z3JT66iaN8I6DwRFA/0?wx_fmt=jpeg" data-croporisrc="https://mmbiz.qpic.cn/mmbiz_jpg/TrW9NKr3777ibcDzjo9N6SlHXUnvpicXxov0nDrqZGibJWEpeBwIXCOtvRnBLiaFqjPMMeTtOKa51v1WTzMByDiahTg/0?wx_fmt=jpeg" data-cropx1="0" data-cropx2="1280" data-cropy1="153.69175627240142" data-cropy2="961.1469534050178" data-imgfileid="100008227" data-ratio="0.6305555555555555" data-s="300,640" data-type="jpeg" data-w="1080" src="/assets/images/25d3adf87a.jpg" style="letter-spacing: 0.578px;text-wrap: wrap;text-align: center;width: 578px;"/>
     </span>
    </section>
    <section style="margin-left: 16px;margin-right: 16px;">
     <br/>
    </section>
    <section style="margin-left: 16px;margin-right: 16px;">
     <span style="font-size: 14px;">
      潜动谱有二十多个阶段及状态的标记（见上图），每一个都有自己名字和图形符号——这给参与者提供了一幅观看以及练习接触即兴的全局地图。不过，它提供的只是一个框架而非限制，我们可以基于个人独特的身体、背景、经验以及敏感度，在其中自由地进行个人化的表达和共同创造，观察并探索不同的人与人、与空间、与音乐、与群组、与环境间的关系的可能。虽然是大家一起跳舞，但是它并不讲究舞步动作的正确与否，反而强调从内在去经验动作，允许舞蹈自己发生。人们在其中阅读时间、空间和关系，觉察自己及他人的身体，探索、发展和见证各种可能性。
     </span>
     <o:p>
     </o:p>
    </section>
    <section style="margin-left: 16px;margin-right: 16px;">
     <span style="font-size: 14px;">
      <br/>
     </span>
    </section>
    <section style="margin-left: 16px;margin-right: 16px;">
     <span style="font-size: 14px;">
      潜动谱练习一般持续三到四个小时，通过一系列充满活力的状态来向前推进，既包括长时间的细微、个人的、内在的活动，也包括较高的能量状态和与他人的互动。通过单人、双人或者多人的接触即兴，小组的循环和交互，逐渐开放到带着编舞意识的全体成员即兴的参与，最后回到休息和沉思。
     </span>
     <o:p>
     </o:p>
    </section>
    <section style="margin-left: 16px;margin-right: 16px;">
     <br/>
    </section>
    <section style="margin-left: 16px;margin-right: 16px;">
     <strong>
      <span style="font-size: 14px;">
       相对于日常舞酱来说，潜动谱更具有组织性和焦点，练习中有更多的整体协调。
      </span>
     </strong>
     <span style="font-size: 14px;">
      人们一起开始，并遵循更多共同的轨迹。
     </span>
     <span style='font-size: 14px;font-family: mp-quote, -apple-system-font, BlinkMacSystemFont, "Helvetica Neue", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei UI", "Microsoft YaHei", Arial, sans-serif;letter-spacing: 0.034em;'>
      就我个人的理解来说，它有一点像对于我自身，同时也是对所在
     </span>
     <span style='font-size: 14px;font-family: mp-quote, -apple-system-font, BlinkMacSystemFont, "Helvetica Neue", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei UI", "Microsoft YaHei", Arial, sans-serif;letter-spacing: 0.034em;'>
      CI
     </span>
     <span style='font-size: 14px;font-family: mp-quote, -apple-system-font, BlinkMacSystemFont, "Helvetica Neue", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei UI", "Microsoft YaHei", Arial, sans-serif;letter-spacing: 0.034em;'>
      群体的接触即兴实践的一个稍微有一点结构的、阶段性的回顾。
     </span>
    </section>
    <section style="margin-left: 16px;margin-right: 16px;">
     <span style='font-size: 14px;font-family: mp-quote, -apple-system-font, BlinkMacSystemFont, "Helvetica Neue", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei UI", "Microsoft YaHei", Arial, sans-serif;letter-spacing: 0.034em;'>
      <br/>
     </span>
    </section>
    <section style="margin-right: 16px;margin-bottom: 0px;margin-left: 16px;letter-spacing: 0.578px;text-wrap: wrap;">
     <span style="font-size: 14px;">
      “越来越感觉参加潜动谱就像走进一次回忆，之前课程、工作坊，还有接触即兴中的自己，甚至人生中的片段都落入谱中，化作了一个个符号，一首首歌曲。似乎听到看到了谱中自己和他人一起哼唱应和的歌。这回忆是一种开启，看到潜动谱，就感到还有很广阔的空间和可能。现在如果用一句话来说潜动谱，我会说它是关于看见和打开
     </span>
     <span style="font-size: 14px;">
      的。”
     </span>
     <o:p>
      <span style="font-size: 14px;">
       ——这是几年前我个人的练习感受。
      </span>
     </o:p>
    </section>

    <section style="margin-left: 16px;margin-right: 16px;">
     <span style="font-size: 14px;">
      潜动谱练习分为
      <strong>
       讲述部分
      </strong>
      和
      <strong>
       练习部分
      </strong>
      ，第一部分为讲述环节，带领者会对舞谱进行讲解，舞谱进展轨迹的轮廓会在讲述中被传达。这个讲述是舞谱的一部分，它有助于练习部分的发展和进行，也可以为即兴创作过程带来有趣的洞见。
     </span>
     <span style='font-size: 14px;font-family: mp-quote, -apple-system-font, BlinkMacSystemFont, "Helvetica Neue", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei UI", "Microsoft YaHei", Arial, sans-serif;letter-spacing: 0.034em;text-decoration: underline;'>
      第一次参加潜动谱的朋友请务必参加讲述环节。
