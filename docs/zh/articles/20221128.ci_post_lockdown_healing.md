       <strong style='font-family: mp-quote, -apple-system-font, BlinkMacSystemFont, "Helvetica Neue", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei UI", "Microsoft YaHei", Arial, sans-serif;box-sizing: border-box;'>

      <p style="margin-right: 0cm;margin-left: 0cm;font-size: 10.5pt;font-family: Calibri;color: rgb(0, 0, 0);white-space: normal;margin-bottom: 0px;padding-right: 20px;padding-left: 20px;line-height: 2;letter-spacing: 1px;box-sizing: border-box;">
       <span lang="ZH-CN" style="font-family: 宋体;">
        2018年底我遭遇了一些重大创伤，之后一直都缓不过来，我记得当时自己每天失眠，每天都很紧张，不敢和人说话，走在路上也要紧紧抱着自己，总之怎么都放松不下来。很渴望被拥抱，但是当时就是没有这样的“resource”，我知道如果有拥抱或有身体接触，就能放松下来。
       </span>
      </p>
      <p style="margin-right: 0cm;margin-left: 0cm;font-size: 10.5pt;font-family: Calibri;color: rgb(0, 0, 0);white-space: normal;margin-bottom: 0px;padding-right: 20px;padding-left: 20px;line-height: 2;letter-spacing: 1px;box-sizing: border-box;">
       <br/>
      </p>
      <p style="margin-right: 0cm;margin-left: 0cm;font-size: 10.5pt;font-family: Calibri;color: rgb(0, 0, 0);white-space: normal;margin-bottom: 0px;padding-right: 20px;padding-left: 20px;line-height: 2;letter-spacing: 1px;box-sizing: border-box;">
       <span lang="ZH-CN" style="font-family: 宋体;">
        我于是想起曾经在某位朋友的朋友圈看到过有关接触即兴的介绍和课程信息，当时并不知道“接触即兴”具体是什么，但看这个名字，觉得应该是有“身体接触”的，于是，我就打着“学习舞蹈”的幌子，带着“私人”的目的，去到了Zoe老师的课堂。
       </span>
      </p>
      <p style="margin-right: 0cm;margin-left: 0cm;font-size: 10.5pt;font-family: Calibri;color: rgb(0, 0, 0);white-space: normal;margin-bottom: 0px;padding-right: 20px;padding-left: 20px;line-height: 2;letter-spacing: 1px;box-sizing: border-box;">
       <br/>
      </p>
      <p style="margin-right: 0cm;margin-left: 0cm;font-size: 10.5pt;font-family: Calibri;color: rgb(0, 0, 0);white-space: normal;margin-bottom: 0px;padding-right: 20px;padding-left: 20px;line-height: 2;letter-spacing: 1px;box-sizing: border-box;">
       <span lang="ZH-CN" style="font-family: 宋体;">
        事实上，在第一次上课的时候，我就产生很大的反应，在引导练习的最后，Zoe老师让我们大家抱在一起，我突然觉得身体里被压抑的情绪和恐惧要喷涌而出，但那一次我强行压抑了自己，没有释放出来。
       </span>
      </p>
      <p style="margin-right: 0cm;margin-left: 0cm;font-size: 10.5pt;font-family: Calibri;color: rgb(0, 0, 0);white-space: normal;margin-bottom: 0px;padding-right: 20px;padding-left: 20px;line-height: 2;letter-spacing: 1px;box-sizing: border-box;">
       <br/>
      </p>
      <p style="margin-right: 0cm;margin-left: 0cm;font-size: 10.5pt;font-family: Calibri;color: rgb(0, 0, 0);white-space: normal;margin-bottom: 0px;padding-right: 20px;padding-left: 20px;line-height: 2;letter-spacing: 1px;box-sizing: border-box;">
       <span lang="ZH-CN" style="font-family: 宋体;">
        但这些情绪终究还是爆发出来，在第二次舞酱（Jam）的时候，当我和一位同学刚跳完，然后突然就开始呼吸困难，大口喘气，然后压抑淤积多时的能量便如洪水般泄出，我又是尖声喊叫，又是悲伤痛哭。这样强烈的发作，把周围跳舞的同学都吓了一大跳，他们全都停下来看我，但当我哭完了，他们便又若无其事地继续跳舞了。我心想：“他们一定都把我当成疯子了，肯定不会再有人要跟我跳舞了，Zoe也不会想让我再来上课了。”但没想到，当我准备离开去和Zoe道别时，她张开双臂拥抱我，并对我说，欢迎下次再来。
       </span>
      </p>
      <p style="margin-right: 0cm;margin-left: 0cm;font-size: 10.5pt;font-family: Calibri;color: rgb(0, 0, 0);white-space: normal;margin-bottom: 0px;padding-right: 20px;padding-left: 20px;line-height: 2;letter-spacing: 1px;box-sizing: border-box;">
       <br/>
      </p>
      <p style="margin-right: 0cm;margin-left: 0cm;font-size: 10.5pt;font-family: Calibri;color: rgb(0, 0, 0);white-space: normal;margin-bottom: 0px;padding-right: 20px;padding-left: 20px;line-height: 2;letter-spacing: 1px;box-sizing: border-box;">
       <span lang="ZH-CN" style="font-family: 宋体;">
        时至今日想起这个画面，我依旧有些感动，而我的CI之旅，也就从那时正式开启了……
       </span>
      </p>

              <span lang="ZH-CN" style="font-size: 18px;font-family: 宋体;">
               接触即兴与羞耻感
              </span>
             </strong>
            </span>
           </strong>
           <span style="color: rgb(62, 62, 62);font-size: 18px;text-align: left;font-family: Calibri;">
           </span>
          </p>
         </section>
        </section>
       </section>

      <section powered-by="xiumi.us" style="margin-right: 0cm;margin-bottom: 0px;margin-left: 0cm;padding-right: 20px;padding-left: 20px;font-size: 10.5pt;font-family: Calibri;color: rgb(0, 0, 0);white-space: normal;line-height: 2;letter-spacing: 1px;box-sizing: border-box;">
       <p style="margin-right: 0cm;margin-left: 0cm;font-size: 10.5pt;">
        <br/>
       </p>
       <p style="font-size: 10.5pt;font-family: Calibri;color: rgb(0, 0, 0);white-space: normal;margin-left: 16px;margin-right: 16px;">
        <span lang="ZH-CN" style="font-family: 宋体;">
         曾在私底下问过几位跳接触即兴的朋友，在初学接触即兴时，遇到的难点是什么，每个人都给出了各自的答案，听下来我的感觉是，基本上每个人在进入接触即兴时，都有各自要突破的点，有些是身体上的障碍，有些是心理上障碍。
        </span>
       </p>
       <p style="font-size: 10.5pt;font-family: Calibri;color: rgb(0, 0, 0);white-space: normal;margin-left: 16px;margin-right: 16px;">
        <span lang="ZH-CN" style="font-family: 宋体;">
         <br/>
        </span>
       </p>
       <p style="font-size: 10.5pt;font-family: Calibri;color: rgb(0, 0, 0);white-space: normal;margin-left: 16px;margin-right: 16px;">
        <span lang="ZH-CN" style="font-family: 宋体;">
         我当然也有我的障碍，我的障碍就是羞耻感。
        </span>
       </p>
       <p style="font-size: 10.5pt;font-family: Calibri;color: rgb(0, 0, 0);white-space: normal;margin-left: 16px;margin-right: 16px;">
        <span lang="ZH-CN" style="font-family: 宋体;">
         <br/>
        </span>
       </p>
       <p style="font-size: 10.5pt;font-family: Calibri;color: rgb(0, 0, 0);white-space: normal;margin-left: 16px;margin-right: 16px;">
        <span lang="ZH-CN" style="font-family: 宋体;">
         虽然我渴望身体接触，但在大庭广众下，和人这么近距离接触，尤其是和男性有这么亲密的身体接触，还是会感到羞耻。
        </span>
       </p>
       <p style="font-size: 10.5pt;font-family: Calibri;color: rgb(0, 0, 0);white-space: normal;margin-left: 16px;margin-right: 16px;">
        <span lang="ZH-CN" style="font-family: 宋体;">
         <br/>
        </span>
       </p>
       <p style="font-size: 10.5pt;font-family: Calibri;color: rgb(0, 0, 0);white-space: normal;margin-left: 16px;margin-right: 16px;">
        <span lang="ZH-CN" style="font-family: 宋体;">
         当我与
        </span>
        A
        <span lang="ZH-CN" style="font-family: 宋体;">
         男生跳过之后，然后又去和
        </span>
        B
        <span lang="ZH-CN" style="font-family: 宋体;">
         男生跳舞，我也会感到羞耻，我心里想，
        </span>
        A
        <span lang="ZH-CN" style="font-family: 宋体;">
         男生会不会对我有看法。（这样的想法现在看来很可笑，但当时却是真实的）。
        </span>
       </p>
       <p style="font-size: 10.5pt;font-family: Calibri;color: rgb(0, 0, 0);white-space: normal;margin-left: 16px;margin-right: 16px;">
        <span lang="ZH-CN" style="font-family: 宋体;">
         <br/>
        </span>
       </p>
       <p style="font-size: 10.5pt;font-family: Calibri;color: rgb(0, 0, 0);white-space: normal;margin-left: 16px;margin-right: 16px;">
        <span lang="ZH-CN" style="font-family: 宋体;">
         同时我还有“双重羞耻”，我觉得我不应该羞耻，我想我是女权主义者，我又学习了如此多的性别理论，上述两种情况完全不应该羞耻，但为什么我还是羞耻，我为自己“羞耻”而“羞耻”。
        </span>
       </p>
       <p style="font-size: 10.5pt;font-family: Calibri;color: rgb(0, 0, 0);white-space: normal;margin-left: 16px;margin-right: 16px;">
        <span lang="ZH-CN" style="font-family: 宋体;">
         <br/>
        </span>
       </p>
       <p style="font-size: 10.5pt;font-family: Calibri;color: rgb(0, 0, 0);white-space: normal;margin-left: 16px;margin-right: 16px;">
        <span lang="ZH-CN" style="font-family: 宋体;">
         我于是意识到，对身体、对异性、对接触的羞耻感，是被主流教育和社会规训烙印在身体里的，是经由遗传一代代地传递至自己身体里的，虽然学习了如此多的理论和知识，但认知层面头脑层面的的调整，并不能改变身体，我无法通过说服自己而让自己不羞耻。
        </span>
       </p>
       <p style="font-size: 10.5pt;font-family: Calibri;color: rgb(0, 0, 0);white-space: normal;margin-left: 16px;margin-right: 16px;">
        <span lang="ZH-CN" style="font-family: 宋体;">
         <br/>
        </span>
       </p>
       <p style="font-size: 10.5pt;font-family: Calibri;color: rgb(0, 0, 0);white-space: normal;margin-left: 16px;margin-right: 16px;">
        <span lang="ZH-CN" style="font-family: 宋体;">
         然而最令我感到羞耻的，是我意识到，相较于和女性跳舞，我更喜欢和男性跳舞，我感受到身体里想要与男性一起跳舞的冲动和身体里的羞耻感，我同时感到这个两者。
        </span>
       </p>
       <p style="font-size: 10.5pt;font-family: Calibri;color: rgb(0, 0, 0);white-space: normal;margin-left: 16px;margin-right: 16px;">
        <span lang="ZH-CN" style="font-family: 宋体;">
         <br/>
        </span>
       </p>
       <p style="font-size: 10.5pt;font-family: Calibri;color: rgb(0, 0, 0);white-space: normal;margin-left: 16px;margin-right: 16px;">
        <span lang="ZH-CN" style="font-family: 宋体;">
         如今，这些羞耻感早已经离我远去，在舞酱中和任何人（无论男性还是女性）跳舞，我都不会有心理障碍了，和伙伴们滚在一起似乎是再自然不过的事情。然而在当时，确实花了很多努力来突破那个点。
        </span>
       </p>
       <p style="font-size: 10.5pt;font-family: Calibri;color: rgb(0, 0, 0);white-space: normal;margin-left: 16px;margin-right: 16px;">
        <span lang="ZH-CN" style="font-family: 宋体;">
         <br/>
        </span>
       </p>
       <p style="font-size: 10.5pt;font-family: Calibri;color: rgb(0, 0, 0);white-space: normal;margin-left: 16px;margin-right: 16px;">
        <span lang="ZH-CN" style="font-family: 宋体;">
         记得当时在心里对自己说：“陈峻，如果你就是喜欢和男性黏在一起，滚在一起，抱在一起，就这么去做吧
        </span>
        ——
        <span lang="ZH-CN" style="font-family: 宋体;">
         做真实的自己。”
        </span>
       </p>
