     <strong>

       笼统而言，
      </span>
     </strong>
     <strong>
      <span style="font-family: 宋体;font-size: 14px;">
       我们可以说
      </span>
      <span style="font-family: 宋体;font-size: 14px;">
       “为什么动”指向的是精神表达之强度。
      </span>
     </strong>
     <span style="font-family: 宋体;font-size: 14px;">
      风格如舞蹈剧场、舞踏等，艺术家如皮娜、玛姬马汉、帕帕约安努等，呈现出强烈的个人风格、情感、精神性。
     </span>
     <span style="font-family: 宋体;font-size: 14px;">

     </span>
     <span style="font-family: 宋体;font-size: 14px;">

     </span>
     <span style="font-family: 宋体;font-size: 14px;">
      可能跟素人演员合作，有去舞蹈化动作的倾向。会涉猎、跨领域到戏剧、美术、文学等领域。
     </span>
     <strong>
      <span style="font-family: 宋体;font-size: 14px;">

    <p>
     <strong>
      <span style="font-family: 宋体;font-size: 14px;">
       “怎么动”指向的是身体语言之深度。
      </span>
     </strong>
     <span style="font-family: 宋体;font-size: 14px;">
      风格如先锋派、放松技术、“纯肢体”等，艺术家如坎宁汉、崔莎、安娜特蕾莎
     </span>
     <span style="font-family: 宋体;font-size: 14px;">
      <span style="font-family:宋体;">
       等，
      </span>
     </span>
     <span style="font-family: 宋体;font-size: 14px;">
      <span style="font-family:宋体;">
       倾向于干净的呈现身体自身，要求对身体的了解和控制能力，选用完全紧身或仅仅是穿着很舒服的衣服。通过对多余信息的剥离，呈现身体本体的运动。音乐也可以不要，舞台尽可以干净。
       <strong>
        他们想让你看的，只有身体。
       </strong>
      </span>
