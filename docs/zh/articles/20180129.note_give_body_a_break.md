    <p>
     <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">
      有人问，既然是即兴，那还需要教吗？当这些老师们在教接触即兴时，他们到底在教什么呢？CI是很难教的，因为可能舞者自己都难以重复刚才的舞动，甚至完全忘记了刚才做了什么。这是一个很有意思的问题。在这《CI》这本书中，作者也正好说到了这个问题。经过不断的交流和反思，
     </span>
     <span style="font-family: 微软雅黑, sans-serif;color: rgb(255, 41, 65);">
      接触即兴
     </span>
     <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">
      的舞者们确实发现了一些
     </span>
     <span style="font-family: 微软雅黑, sans-serif;color: rgb(255, 41, 65);">
      基本元素
     </span>
     <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">
      ，这些基本元素是什么呢？我们一个个来看。先说第一个：“建立接触”。
     </span>
    </p>
    <p style="text-align: center;">
     <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">

    <p>
     <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">
      接触即兴中，动作从何而来？工作坊中有老师不断提这个问题。我逐渐意识到这个问题的重要性，接触即兴中动作应该都与接触点有关，从那里生发出来。如果忽视了这一点，就只是表面的接触而已（假接触，还是自己在玩自己的），失去了接触的真意。我们是真正在接触，还是只不过表面上碰到了一起而已？真正的接触是会带来变化的。
     </span>
    </p>
    <p style="text-align: center;">
     <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">
      <br/>
     </span>
    </p>
    <p>
     <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">
      关注自身，还是关注接触？这是一个焦点的转换。随着我们越来越关注接触点，而非自身，我们就从自己的习惯模式中走了出来，走向与对方的互动，走向未知和变化的更有意思的世界。
     </span>
    </p>
    <p>
     <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">
      <br/>
     </span>
    </p>
    <p>
     <em>
      <span style="font-size:14px;font-family:微软雅黑,sans-serif;color:green;">
       “接触点并没有对或者错，但为了让舞动继续下去，舞者必须建立起一个身体的连接，并且相互保持接触。如果连接始终没有建立起来，那这个就不是
      </span>
     </em>
     <em>
      <span style="font-size:14px;font-family:微软雅黑,sans-serif;color:green;">
       CI
      </span>
     </em>
     <em>
      <span style="font-size:14px;font-family:微软雅黑,sans-serif;color:green;">
       了。”

    <p>
     <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">
      如果连接始终没有建立起来，那就不是
     </span>
     <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">
      CI
     </span>
     <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">
      了。在
     </span>
     <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">
      CI
     </span>
     <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">
      中，连接是必要的，它很多时候、很大程度上体现于身体的触碰，但也不限于此。身体偶尔分离，但连接的感觉不断，这种情况也经常出现，就像书法中的形断意连。如果没有建立起这个“连接”，那么这就不是
     </span>
     <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">
      CI
     </span>
     <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">
      了。对连接的重视，这是
     </span>
     <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">
      CI
     </span>
     <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">
      的根本，本立而道生。
     </span>
    </p>
    <p>
     <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">
      当然，在接触即兴的活动中，也有一个人独处的时候，也有独舞。我理解在
     </span>
     <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">
      CI
     </span>
     <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">

      </span>
     </em>

    <p>
     <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">
      从一种试探开始，尤其是跟新搭档一起跳的时候，而非一下子就贸然动作，这是一个很重要的原则。即使是熟悉的伙伴，她也可能有不同的身体状况，因此慢慢地进入总是合适的。接触首先是一种信息的交流。
     </span>
    </p>
    <p style="text-align: center;">
     <br/>
    </p>
    <p>
     <em>
      <span style="font-size:14px;font-family:微软雅黑,sans-serif;color:green;">
       “在
      </span>
     </em>
     <em>
      <span style="font-size:14px;font-family:微软雅黑,sans-serif;color:green;">
       CI
      </span>
     </em>
     <em>
      <span style="font-size:14px;font-family:微软雅黑,sans-serif;color:green;">
       中，传统的观众与表演者关系被翻转了，舞者的内在体验比呈现给观众的表现更为重要。”
      </span>
     </em>
    </p>
    <p>
     <em>
      <span style="font-size:14px;font-family:微软雅黑,sans-serif;color:green;">
       <br/>
      </span>
     </em>
    </p>
    <p>
     <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">
      从这点来说，接触即兴不是一个“表演”，它更多的是舞者之间的探索。至于它是否好看，并不是主要的关注因素。专业舞者的动作很优美，但那不是
     </span>
     <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">
      CI
     </span>
     <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">
      中所追求的东西。一味追求美是一种限制。
     </span>
    </p>

    <p>
     <span style="font-family: 微软雅黑, sans-serif;color: rgb(31, 73, 125);">
      “即兴”是第二个关键字，
     </span>
     <span style="font-family: 微软雅黑, sans-serif;color: rgb(31, 73, 125);">
      CI
     </span>
     <span style="font-family: 微软雅黑, sans-serif;color: rgb(31, 73, 125);">
      要求舞者去体验当下，从当下中寻找到动作，而不是预先设计。即兴是对未知的敞开。注意，这里用的是
     </span>
     <span style="font-family: 微软雅黑, sans-serif;color: rgb(31, 73, 125);">
      improvising
     </span>
     <span style="font-family: 微软雅黑, sans-serif;color: rgb(31, 73, 125);">
      ，是一种连续不断的状态，这是一种觉察和专注的练习。
     </span>
    </p>
    <p>
     <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">
      <br/>
     </span>
    </p>
    <p>
     <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">
      打开感官去细细感觉，就会发现瞬间发生的事情太多了，这些都可以成为变化之源，因此即兴可以使得这个舞蹈非常丰富，变化无尽。这种感觉并非只是对外界的感知，也包括对自身内在状态的觉察，包括肌肉骨骼关节，也包括对当时的心境等。舞者可以将自己内在的状态（心境、意图）通过动作表现出来，也可以吸收搭档和外界的信息，将其纳入自己的动作。内与外之间不断在寻找和达成一种互动和平衡，不断吐纳。
     </span>
    </p>
    <p>
     <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">
      <br/>
     </span>
    </p>
    <p>
     <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">
      <img class="" data-copyright="0" data-ratio="0.66640625" data-s="300,640" data-type="jpeg" data-w="1280" src="/assets/images/2feb9ffffc.jpg" style="color: rgb(31, 73, 125);font-family: 微软雅黑, sans-serif;white-space: normal;"/>
     </span>
    </p>
    <p>
     <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">
     </span>
    </p>
    <p>
     <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">
      <span style="font-family: 微软雅黑, sans-serif;font-size: 12px;color: rgb(0, 0, 0);">
       照片摄于乌镇艺术节户外嘉年华
      </span>
     </span>
    </p>
    <p>
     <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">
      <span style="font-family: 微软雅黑, sans-serif;font-size: 12px;color: rgb(0, 0, 0);">
       <br/>
      </span>
     </span>
    </p>
    <p>
     <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">
      说到即兴，很多时候生活都是模式化的，让我们忘记了生活本应该是一个即兴过程。接触即兴是一个打破模式、重新学习即兴的方式。“接触”和“即兴”是两个基本元素，细品一下，这两个元素之间又有很多关联。越是变化越是稳定和健壮。
     </span>
    </p>
    <p style="text-align: center;">
     <br/>
    </p>
    <ul class="list-paddingleft-2" style="list-style-type: disc;">
     <li>
      <p style="margin-top:auto;margin-bottom:auto;">
       <strong>
        <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">
         保持中心的重要性（
        </span>
       </strong>
       <strong>
        <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">
         The Importance of Centering
        </span>
       </strong>
       <strong>
        <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">
         ）
        </span>
       </strong>
      </p>
      <p style="margin-top:auto;margin-bottom:auto;">
       <strong>
        <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">
        </span>
       </strong>
      </p>
      <p style="margin-top:auto;margin-bottom:auto;">
       <strong>
        <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">
         <br/>
        </span>
       </strong>
      </p>
     </li>
    </ul>
    <p>
     <em>
      <span style="font-size:14px;font-family:微软雅黑,sans-serif;color:green;">
       “保持中心意味着保持一种放松又有准备的状态，为相遇做好准备，在需要的时候能够从意料之外的，冒险的动作中回复过来。”
      </span>
     </em>
     <em>
      <span style="font-size:14px;font-family:微软雅黑,sans-serif;color:green;">
      </span>
     </em>
    </p>
    <p>
     <em>
      <span style="font-size:14px;font-family:微软雅黑,sans-serif;color:green;">
       <br/>
      </span>
     </em>
    </p>
    <p>
     <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">
      时时保持一种有准备的状态，不要失去中心（中正）。这也是太极里非常重要的原则。这种中心并不是指身体姿态四平八稳，而是无论身体处于何种姿态，都保持一种中正之意，这种中正感让自己对变化留有更多的余地，让自己在可能失衡的时候仍可以用某种方式化解（消解）受伤的危险。
     </span>
    </p>
    <p>
     <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">
      <br/>
     </span>
    </p>
    <p>
     <img class="" data-copyright="0" data-ratio="0.6265625" data-s="300,640" data-type="jpeg" data-w="1280" src="/assets/images/baf4f75de4.jpg" style=""/>
    </p>
    <p>
     <em>
      <span style="font-size:14px;font-family:微软雅黑,sans-serif;color:green;">
       <span style="font-size: 14px;font-family: 微软雅黑, sans-serif;color: rgb(0, 0, 0);">
        <span style="font-family: 微软雅黑, sans-serif;font-size: 12px;text-align: center;">
         照片来自微微艺术节
        </span>
       </span>
      </span>
     </em>
    </p>
    <p>
     <em>
      <span style="font-size:14px;font-family:微软雅黑,sans-serif;color:green;">
       <span style="font-size: 14px;font-family: 微软雅黑, sans-serif;color: rgb(0, 0, 0);">
        <span style="font-family: 微软雅黑, sans-serif;font-size: 12px;text-align: center;">
         <br/>
        </span>
       </span>
      </span>
     </em>
    </p>
    <p>
     <em>
      <span style="font-size:14px;font-family:微软雅黑,sans-serif;color:green;">
       “通常需要舞者自己为自己负责，他们必须对自己的机能（技能）心中有数，知道什么样程度的冒险是自己能够把控的。……接触即兴中身体的互动意味着舞者的责任自然也包括了对搭档的责任，但这并非父母照顾孩子那样的责任。在舞蹈中，责任主要在自己身上。”
      </span>
     </em>
    </p>
    <p>
     <em>
      <span style="font-size:14px;font-family:微软雅黑,sans-serif;color:green;">
       <br/>
      </span>
     </em>
    </p>
    <p>
     <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">
      这是一个非常重要的原则，即对自己负责。搭档固然会予以支持，但主要的责任仍然在每个舞者自己身上。不要做超出自己掌控范围的冒险。只有自己才知道自己，只有自己才能保护自己。接触即兴中有冒险，但并不疯狂。
     </span>
    </p>
    <p>
     <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">
      <br/>
     </span>
    </p>
    <p>
     <em>
      <span style="font-size:14px;font-family:微软雅黑,sans-serif;color:green;">
       “强健的中心是流动而富于回应的，并不僵硬。它能够承受，抗拒，克服，但同时知道自己的边界在哪里。它是自足的，无需向外寻求什么……强健的中心是稳定的，有根的，它能够承担责任，可以被预期，并且直接了当地面对生活，立足非常稳固。”
      </span>
     </em>
    </p>
    <p>
     <em>
      <span style="font-size:14px;font-family:微软雅黑,sans-serif;color:green;">
       <br/>
      </span>
     </em>
    </p>
    <p>
     <span style="font-family:微软雅黑,sans-serif;color:#1F497D;">
      这难道不是一种理想的人生态度吗？接触即兴就是生活吧。
     </span>
    </p>
