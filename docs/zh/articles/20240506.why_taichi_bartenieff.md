   <h1 class="rich_media_title">
    为什么把太极和巴特尼芙基本动作放到一起练习？
   </h1>
   <div class="rich_media_content js_underline_content defaultNoSetting" id="js_content" style=" ">
    <section style="line-height: 1.75em;">
     <span style='font-family: mp-quote, -apple-system-font, BlinkMacSystemFont, "Helvetica Neue", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei UI", "Microsoft YaHei", Arial, sans-serif;letter-spacing: 0.034em;font-size: 14px;'>

      <img class="rich_pages wxw-img" data-cropselx1="0" data-cropselx2="578" data-cropsely1="0" data-cropsely2="434" data-imgfileid="100007991" data-ratio="0.75" data-w="1080" src="/assets/images/39588876ee.jpg" style="height: 433px;width: 578px;"/>
     </span>
    </section>
    <section style="margin-left: 16px;margin-right: 16px;line-height: 1.75em;">
     <br/>
    </section>
    <p style="margin-left: 8px;margin-right: 8px;">
     <span style="font-size: 14px;">
      一位参与公开课的朋友提了一个问题：
      <strong>
       把太极和巴特尼芙基本动作（Bartenieff Fundamentals，简称BF）放在一起，会不会导致两个都没学好？
      </strong>
     </span>
    </p>
    <p style="margin-left: 8px;margin-right: 8px;">
     <span style="font-size: 14px;">
      <br/>
     </span>
    </p>
    <p style="margin-left: 8px;margin-right: 8px;">
     <span style="font-size: 14px;">
      这个问题当时把我问住了。就自身而言，
      <strong>
       我是在自己的练习过程中感受到两者相互助益才开发出这个课程，并非刻意要把风马牛不相及的东西硬拉到一起。两者自然地结合在了一起，不存在一个干扰或削弱另一个的情况，倒有点像金庸小说里双剑合璧，本来是各练各的，但配合在一起使用时却突然威力大增。
      </strong>
      我从没有从提问者的角度去想过这个问题，在有点懵圈之后，我觉得确实需要多一点对巴特尼芙基本动作的介绍，以帮助读者了解为什么可以把两者结合在一起。
     </span>
     <o:p>
     </o:p>
    </p>
    <p style="margin-left: 8px;margin-right: 8px;">
     <span style="font-size: 14px;">
      <br/>
     </span>
    </p>
    <p style="margin-left: 8px;margin-right: 8px;">
     <span style="font-size: 14px;">
      巴特尼芙基本动作是由伊尔姆加德·巴特尼芙 (Irmgard Bartenieff, 1900-1981) 开发的一套关注身体整合与和谐的身心学练习体系。创始人巴特妮芙曾随鲁道夫·拉班 (Rudolf Laban, 1879-1958) 学习，因此“巴特妮芙基本动作”也被认为是拉班动作分析的拓展应用。
     </span>
    </p>
    <p style="margin-left: 8px;margin-right: 8px;">
     <strong>
      <span style="font-size: 14px;">
       要认识巴特尼芙基本动作Bartenieff Fundamentals （BF）——首先需要理解什么是“Fundamental”。
      </span>
     </strong>
     <span style="font-size: 14px;">
      一开始我并没有很在意这个词，直到真正对BF有所感觉时才真正理解了它的含义。Fundamental是什么？这个词在词典中的解释为：“基础、基本原理、基本规律和根本法则”。在物理学中，我们说万有引力定律是基本的，因为它是一个普遍规律，具有广大的适用性和客观性。由此可知，BF是一套针对身体和动作本质的，基本的、具有广泛适用性的系统。其实我觉得BF被翻译为“巴特尼芙基本动作”其实并不合适，它的重点并非仅是一套动作（虽然它确实有一套动作练习），而是一种“
      <strong>
       基本的东西
      </strong>
      ”，基本原理，基本规律。如果把它理解为一套动作就大大缩减了其意义。然而这个名字已经被广泛使用，我们也不去改它，但需要理解它的含义才好。
     </span>
     <o:p>
     </o:p>
    </p>
    <p style="margin-left: 8px;margin-right: 8px;">
     <span style="font-size: 14px;">
      <br/>
     </span>
    </p>
    <p style="margin-left: 8px;margin-right: 8px;">
     <em>
      <span style="text-decoration: underline;font-size: 16px;">
       <strong>
        对于身体和动作来说，什么能称之为“基本”呢？
       </strong>
      </span>
     </em>
     <span style="font-size: 14px;">
      <br/>
     </span>
    </p>
    <p style="margin-left: 8px;margin-right: 8px;">
     <span style="font-size: 14px;">
      巴特尼芙和她的学生们一定会经常思考这个问题，长时间浸淫于身体动作的工作中之后，答案才逐渐清晰地显现出来。
     </span>
     <span style="font-size: 14px;">
      待会公布答案之后，你会觉得这个答案非常简单，简单到甚至你觉得自己也能轻易想出来，你会说，“就这？！”。
     </span>
     <span style="font-size: 14px;">
      “简单”，掩盖了它的价值。其实如果让你自己去想，你才会知道要得到最后的这个“简单”（而正确）的东西是多么“不简单”。就这一点我还想说，
      <strong>
       那些觉得BF简单的人其实并没有真正理解它。
      </strong>
     </span>
     <o:p>
     </o:p>
    </p>
    <p style="margin-left: 8px;margin-right: 8px;">
     <span style="font-size: 14px;">
      <br/>
     </span>
    </p>
    <p style="margin-left: 8px;margin-right: 8px;">
     <span style="font-size: 14px;">
      就身体动作而言，到哪里去寻找那些基本的东西呢？如巴特尼芙所说：“
      <strong>
       在新生命的奇迹中，我们认识到在动作中什么是真正的根本。重大的变化发生了，关系被创造出来，关联的模式开始建立，并将在整个生命中延续。
      </strong>
      ”还是要回到最开始的地方。
     </span>
    </p>
    <p style="margin-left: 8px;margin-right: 8px;">
     <span style="font-size: 14px;">
      <br/>
     </span>
    </p>
    <p style="margin-left: 8px;margin-right: 8px;">
     <span style="font-size: 14px;">
      小婴儿从妈妈的子宫内孕育，然后出生到外面的世界中，他/她们缓慢而又迅速地生长。在人生的最初阶段，在与环境的互动中每个人都发展出一套自己的身体姿态和动作模式，这些将成为以后所有复杂动作的基础。这个过程会呈现出一些主要形态，并且依照一定次序显现，巴特尼芙从中识别出身体和动作发展的
      <strong>
       六个序列过程，这就是被称之为“基本”的答案
      </strong>
      ：
     </span>
     <o:p>
     </o:p>
    </p>
    <p style="margin-left: 8px;margin-right: 8px;">
     <span style="font-size: 14px;">
      <br/>
     </span>
    </p>
    <p style="margin-left: 8px;margin-right: 8px;">
     <span style="font-size: 14px;">
      1. 呼吸
     </span>
     <o:p>
     </o:p>
    </p>
    <p style="margin-left: 8px;margin-right: 8px;">
     <span style="font-size: 14px;">
      2. 核心与肢端连接
     </span>
     <o:p>
     </o:p>
    </p>
    <p style="margin-left: 8px;margin-right: 8px;">
     <span style="font-size: 14px;">
      3. 头尾连接
     </span>
     <o:p>
     </o:p>
    </p>
    <p style="margin-left: 8px;margin-right: 8px;">
     <span style="font-size: 14px;">
      4. 上下半身连接
     </span>
     <o:p>
     </o:p>
    </p>
    <p style="margin-left: 8px;margin-right: 8px;">
     <span style="font-size: 14px;">
      5. 左右半身连接
     </span>
     <o:p>
     </o:p>
    </p>
    <p style="margin-left: 8px;margin-right: 8px;">
     <span style="font-size: 14px;">
      6. 身体对侧连接
     </span>
    </p>
    <p style="text-align: center;">
     <img class="rich_pages wxw-img js_insertlocalimg" data-imgfileid="100008197" data-ratio="0.7264150943396226" data-s="300,640" data-type="png" data-w="1060" src="/assets/images/439c1620aa.png" style=""/>
    </p>
    <p style="margin-left: 8px;margin-right: 8px;text-align: center;">
     <span style="color: rgb(136, 136, 136);font-size: 12px;">
      巴特妮芙基本动作6种模式示意图
     </span>
    </p>
    <p style="margin-left: 8px;margin-right: 8px;">
     <span style="font-size: 14px;">
      <br/>
     </span>
    </p>
    <p style="margin-left: 8px;margin-right: 8px;">
     <span style="font-size: 14px;">
      小婴儿的身体动作按照这样一个次序发展：从混沌到分化、从简单到复杂。到一岁左右，小宝宝就完成了这个过程，而此时形成的模式在很大程度上会对一个人的一生产生影响。
      <strong>
       这些身体姿态和动作模式并非只关乎生理层面本身，它们同时具有相应的心理层面的意义。
      </strong>
      在形成最初这些动作模式的同时，小婴儿也形成了一种非常基础的存在模式，相对于意识层面来说可以说这些是更为本真的呈现和表达。从这个意义上来说，关注身体与动作有超越表层的意义，它深入一个人的内在世界——无意识的世界，而身体的改变会自然引起心理状态的变化。譬如从垂头丧气到中正安舒，这种由身体姿态的转变，带来的无论对于自我感觉还是在他人眼中的印象都将自然变化，这一点应该不难理解。
     </span>
     <o:p>
     </o:p>
    </p>
    <p style="margin-left: 8px;margin-right: 8px;">
     <span style="font-size: 14px;">
      <br/>
     </span>
    </p>
    <p style="margin-left: 8px;margin-right: 8px;">
     <span style="font-size: 14px;">
      就这六种模式和连接而言，我们每个人都早已形成了各自的模式，无论目前的状态是什么，是松还是紧，是平衡还是不平衡，是有效还是不那么有效，它们都体现在我们所有的姿态和复杂动作之中，也体现在我们与外部世界产生的关系之中。简单地说，
      <strong>
       巴特尼芙之所以开发出这样一套训练方法，是想帮助人们回到对于基本模式的体验，重新找到和习得一种更有效的身体使用模式，重新具身。
      </strong>
     </span>
     <o:p>
     </o:p>
    </p>
    <p style="margin-left: 8px;margin-right: 8px;">
     <span style="font-size: 14px;">
      <br/>
     </span>
    </p>
    <p style="margin-left: 8px;margin-right: 8px;">
     <strong>
      <span style="font-size: 14px;">
       因为BF关注的是基本的东西，所以它体现在“
       <strong style="letter-spacing: 0.578px;text-wrap: wrap;">
        <span style="font-size: 14px;">
         所有
        </span>
       </strong>
       ”动作之中，理解了这一点，你就不会觉得它与太极相矛盾。
       <span style="font-size: 14px;letter-spacing: 0.578px;text-wrap: wrap;">
       </span>
      </span>
     </strong>
     <span style="font-size: 14px;">
      <span style="font-size: 14px;letter-spacing: 0.578px;text-wrap: wrap;">
       它们
      </span>
      <span style="font-size: 14px;letter-spacing: 0.578px;text-wrap: wrap;">
       所工作的对象是同一个——有心之身
      </span>
      <span style="font-size: 14px;letter-spacing: 0.578px;text-wrap: wrap;">
       。
      </span>
     </span>
     <span style="font-size: 14px;">
      实际上你可以用BF来帮助你来改善任何一种身体运动，但就我个人而言太极与它特别契合，相得益彰。
      <strong>
       BF的模型和练习为太极提供了一个更为简洁整体的骨架、对身体更细微的感知、对动作更多面向的认识，而太极为BF提供了一种极为良好的具身的练习方法。
      </strong>
      譬如BF中的核心与肢端连接，可以与太极中的“腰为主宰”相关联，通过BF中“
      <span style="font-size: 14px;letter-spacing: 0.578px;text-wrap: wrap;">
       核心与肢端连接
      </span>
      ”相关练习而得到体会，会对于做到太极中的“
      <span style="font-size: 14px;letter-spacing: 0.578px;text-wrap: wrap;">
       周
      </span>
      <span style="font-size: 14px;letter-spacing: 0.578px;text-wrap: wrap;">
       身一家，节节贯穿
      </span>
      ”很有帮助，而反过来重复太极拳架练习可以成为具身化这个连接的途径。
     </span>
    </p>
    <p style="margin-left: 8px;margin-right: 8px;">
     <span style="font-size: 14px;">
      <strong>
       <br/>
      </strong>
     </span>
    </p>
    <p style="text-align: center;">
     <img class="rich_pages wxw-img js_insertlocalimg" data-imgfileid="100008199" data-ratio="0.6666666666666666" data-s="300,640" data-type="jpeg" data-w="1080" src="/assets/images/add209f97f.jpg" style=""/>
    </p>
    <p style="margin-left: 8px;margin-right: 8px;">
     <span style="font-size: 14px;">
     </span>
    </p>
    <p style="margin-left: 8px;margin-right: 8px;">
     <em>
      <span style="text-decoration: underline;font-size: 16px;">
       <strong>
        具体如何将太极与BF相结合？
       </strong>
      </span>
     </em>
    </p>
    <p style="margin-left: 8px;margin-right: 8px;">
     <strong>
      <span style="font-size: 14px;color: rgb(255, 104, 39);">
       课程将以太极拳式的学习作为主线，同时辅以BF练习中的探索，从而使太极拳的学习过程带有更加清晰明确的具身意识，而不仅仅是一套太极招式的生搬硬套。
      </span>
      <span style="font-size: 14px;">
      </span>
     </strong>
     <span style="font-size: 14px;">
     </span>
    </p>
    <p style="margin-left: 8px;margin-right: 8px;">
     <span style="font-size: 14px;">
      学习主要会从两方面入手：一方面是通过身心学的练习，引入对BF中六种模式连接的意识和感知，并在太极拳式中加以反复体会；另一方面，课程中会学习巴特尼芙体系中原有的一套基本动作练习，这些练习能够帮助我们对身体的重要关节以及其相互之间的连接关系产生更清晰的感知。需要强调的是，这不是专门的BF教学课程，其落脚点还是在太极上，将BF的内容融合到太极练习之中。
     </span>
    </p>
    <p style="margin-left: 8px;margin-right: 8px;">
     <span style="font-size: 14px;">
      <br/>
     </span>
    </p>
    <p style="margin-left: 8px;margin-right: 8px;">
     <span style="font-size: 14px;">
      希望这篇文章能够解答提问者的疑问，同时这个问题还让我意识到需要告诉大家一件事情：
      <strong>
       我所努力去教的是我自己有所体会的，我觉得真正好的东西。它安静，缓慢，没那么吸引眼球。
      </strong>
      我不会去教，也无法教我自己都没有体验到的东西。同时我特别认同身心学中对第一人称体验的重视，通过课程想要达到的目标一方面是帮助大家更好地进入太极，体会太极之美；另一方面，也许是更根本的方面，是希望经过这个学习
      <strong>
       每个人能够开启对自己身体和动作的持续的探究。
      </strong>
      课程中的所有内容都可以被当作自我探究的工具。
     </span>
    </p>
