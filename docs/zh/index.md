        <span style="font-size: 16px;color: rgb(249, 110, 87);">
         <strong>
          对抗中的平衡
         </strong>
        </span>
       </span>
      </p>
      <p style="text-align: center;text-wrap: wrap;">
       <span style="font-size: 12px;">
        <strong>
         <span style="color: rgb(92, 92, 92);">
          Counter Balance
         </span>
        </strong>
       </span>
      </p>
     </section>
     <section style="font-size: 14px;line-height: 1.75;padding-right: 30px;padding-left: 30px;letter-spacing: 1.75px;">
      <p style="text-wrap: wrap;">
       <br/>
      </p>
     </section>
     <section style="padding-right: 20px;padding-left: 20px;">
      <p style="text-wrap: wrap;">
       <span style="font-size: 14px;">
        去年在日本参加 iDance 的时候，来自以色列的老师 Noam Carmeli 问我们一个问题：「接触即兴」跟「有接触的即兴」有什么区别？（What's the difference between Contact Improvisation and improvisation with contact？）在经历过一轮讨论后，他给予的解释在我看来非常精辟：接触即兴是用重量来沟通（Contact Improvisation is communicate with weight）。而用重量来沟通的本质就是在彼此的对抗与支持之间产生的平衡(Counter Balance)，而同时这也意味着，在力学基础上，我们形成了精妙的作用力和反作用力（力的大小相同，方向相反）。两个人只有彼此在接触点上共享了重量，才能互相聆听到对方的动作、姿势、甚至意图。
       </span>
      </p>
      <p style="text-wrap: wrap;">
       <span style="font-size: 14px;">
        <br/>
       </span>
      </p>
      <p style="text-wrap: wrap;">
       <span style="font-size: 14px;">
        是的，在接触即兴中，Counter Balance 并不只是为了保持身体平衡不倒，做一些惊险的技术动作，而是为了能更好地沟通和交流。
       </span>
       <span style="font-size: 14px;">
        本月我想与大家深入地探讨这种在动态中始终保持的平衡，在牛顿第三定律中共同起舞。
       </span>
      </p>
      <p style="text-wrap: wrap;">
       <br/>
      </p>
      <p style="text-align: center;color: rgb(246, 169, 146);text-wrap: wrap;">
       <span style="color: rgb(92, 92, 92);font-size: 14px;">
        <strong>
         10月19日 主题
        </strong>
       </span>
      </p>
      <p style="text-align: center;color: rgb(246, 169, 146);text-wrap: wrap;">
       <span style="font-size: 14px;color: rgb(249, 110, 87);">
        <strong>
         骨盆的意识
        </strong>
       </span>
      </p>
      <p style="text-align: center;color: rgb(246, 169, 146);text-wrap: wrap;">
       <span style="font-size: 14px;">
        <strong>
         <br/>
        </strong>
       </span>
      </p>
      <p style="text-wrap: wrap;">
       <span style="font-size: 14px;">
        我们会从骨盆的意识开始，骨盆是身体的中心，也是力量和动作的来源。意识到骨盆的位置、方向、倾斜、旋转，以及伙伴的骨盆，可以帮我们更好地聆听伙伴。也能让我们更加清晰、更加轻盈。
       </span>
      </p>
      <p style="text-wrap: wrap;">
       <br/>
      </p>
      <p style="text-align: center;color: rgb(246, 169, 146);text-wrap: wrap;">
       <span style="color: rgb(92, 92, 92);font-size: 14px;">
        <strong>
         10月26日 主题
        </strong>
       </span>
      </p>
      <p style="text-align: center;color: rgb(246, 169, 146);text-wrap: wrap;">
       <span style="font-size: 14px;color: rgb(249, 110, 87);">
        <strong>
         流动的重量
        </strong>
       </span>
      </p>
      <p style="text-align: center;color: rgb(246, 169, 146);text-wrap: wrap;">
       <span style="color: rgb(246, 146, 217);font-size: 14px;">
        <strong>
         <br/>
        </strong>
       </span>
      </p>
      <p style="text-wrap: wrap;">
       <span style="font-size: 14px;">
        我们会尝试让双人舞的结构增加更多的流动，除了骨盆的意识，还有头部、背部和肋骨之间的对抗平衡（ Counter Balance），以及如何借由这样的 Counter Balance 进行下一步的发展。
       </span>
      </p>
