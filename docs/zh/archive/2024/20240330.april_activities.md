       <span style="font-size: 14px;color: rgb(0, 0, 0);">
        潜动谱（Underscore）是Nancy Stark Smith从1990年代开始逐渐发展出来的一个练习和研究舞蹈即兴的框架。它以接触即兴为基础，包括一个清晰的、展现出直觉性进展阶段的结构，同时包括许多类似于舞酱（Jam）的元素。

       <span style="color: rgb(0, 0, 0);font-size: 14px;letter-spacing: 0.034em;">

       </span>
      </section>
      <section style="text-align: justify;line-height: 1.75em;">
       <span style="font-size: 14px;color: rgb(0, 0, 0);">
        在正式进入潜动谱练习之前，带领者会对舞谱进行讲述，进展轨迹的轮廓会在讲述中被传达。对舞谱的讲述是舞谱的一部分，它有助于练习的发展和进行。讲述不仅有助于后续潜动谱练习的进行，也可以为即兴创作过程带来有趣的洞见。
