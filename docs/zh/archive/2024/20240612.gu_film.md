      <p style="text-wrap: wrap;">
       <span style="font-size: 16px;">
        <strong>
         「古舞团」是谁？
        </strong>
       </span>
      </p>
      <p style="text-wrap: wrap;">
       古舞团成立于1993年，由编舞家古名伸所创立，目的在从事现代舞的创作及发表，演出足迹遍及中国台湾、香港、内地、美国、澳洲、法国及英国等地。除了现代舞的创作演出之外，舞团自创团以来就积极地推广即兴舞蹈表演及「接触即兴」的舞蹈方式与观念，也成为中国台湾（乃至整个亚洲地区）唯一以此种表演艺术形式作专业演出的团体。
      </p>
      <p style="text-wrap: wrap;">
       <br/>
      </p>
      <p style="text-wrap: wrap;">
       1992年发表的《我曾经是个编舞者》为首度尝试的作品，1998年发表大型结构即兴作品《猎景》，开始舞团新的表演方向。之后每年推出异于剧场的表演空间作品如《活动画》、《天使・人间》等。2010年推出即兴舞蹈力作《乱码2010》大获观众好评，并获第九届台新艺术奖表演艺术类提名。除了即兴舞蹈的演出与推广，舞团也不断推出现代舞编创作品，包括《心事》、《安魂曲》、《出走》、《交遇》、《记忆拼图》等，作品屡屡受邀赴国际演出。
      </p>
      <p style="text-wrap: wrap;">
       <br/>
      </p>
      <p style="text-wrap: wrap;">
       2011年起，策划与日、港、韩结盟的双年舞展“i-dance”国际爱跳舞即兴节，邀请国际间的即兴好手来台和本地舞者交流演出。
      </p>
      <p style="text-wrap: wrap;">
       <br/>
      </p>
      <p style="text-wrap: wrap;">
       <span style="font-size: 16px;">
        <strong>
         接触即兴在亚洲的发展
        </strong>
       </span>
      </p>
      <p style="text-wrap: wrap;">
       接触即兴起源于1972年的美国，最初在亚洲地区传播较为缓慢。1990年代，中国台湾舞蹈艺术家古名伸在纽约研究接触即兴，并于1992年返台，开设接触即兴课程。同年邀请接触即兴创始人Steve Paxton赴台教学和联合演出，这也是Steve首次赴亚洲。
      </p>
      <p style="text-wrap: wrap;">
       1993年，古名伸成立「古名伸舞团」（简称古舞团），并从此将接触即兴在亚洲地区推广开来。
      </p>
      <p style="text-wrap: wrap;">
       古舞团为亚洲地区的接触即兴发展带来至关重要的力量，而古名伸也因此被许多人称为「亚洲接触即兴之母」。
      </p>
      <p style="text-wrap: wrap;">
       <br/>
      </p>
      <p style="margin-bottom: 0px;font-size: 14px;letter-spacing: 0.578px;text-wrap: wrap;">
       《无动不舞：揭秘接触即兴、漫舞四分之一世纪》
       <br/>
       是2018年由古舞团出版的书籍+影视作品。记录了古名伸及其舞团在亚洲地区推广接触即兴舞蹈25年来的心路历程。
      </p>
      <p style="margin-bottom: 0px;font-size: 14px;letter-spacing: 0.578px;text-wrap: wrap;">
       <br/>
      </p>
      <p style="margin-bottom: 0px;font-size: 14px;letter-spacing: 0.578px;text-wrap: wrap;">

      </p>
