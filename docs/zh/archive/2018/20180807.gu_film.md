     <span style="max-width: 100%;font-size: 16px;font-family: 宋体;box-sizing: border-box !important;word-wrap: break-word !important;">
      在台湾的美丽光谱，细数一路走来的点滴脚步。

    <p style="max-width: 100%;min-height: 1em;box-sizing: border-box !important;word-wrap: break-word !important;">
     <strong style="max-width: 100%;box-sizing: border-box !important;word-wrap: break-word !important;">

    <p style="max-width: 100%;min-height: 1em;box-sizing: border-box !important;word-wrap: break-word !important;">
     <span class="Apple-converted-space">
     </span>
     <span style="max-width: 100%;font-family: 宋体;box-sizing: border-box !important;word-wrap: break-word !important;">
      「接触即兴」酝酿于美国民权运动沸沸扬扬的六零年代，成形于七零年代，强调「人人都可跳舞」的平等精神，是这项身体实践的重要口号。
     </span>
    </p>
    <p style="max-width: 100%;min-height: 1em;box-sizing: border-box !important;word-wrap: break-word !important;">
     <span class="Apple-converted-space">
     </span>
     <span style="max-width: 100%;font-family: 宋体;box-sizing: border-box !important;word-wrap: break-word !important;">
      「接触即兴」，顾名思义「接触」与「即兴」，意思是运用舞者彼此之间的接触所引发的感知与动力，来进行即兴舞蹈的肢体行为，参与者少至两人，多至不限。
     </span>
    </p>
    <p style="max-width: 100%;min-height: 1em;box-sizing: border-box !important;word-wrap: break-word !important;">
     <span class="Apple-converted-space">
     </span>
     <span style="max-width: 100%;font-family: 宋体;box-sizing: border-box !important;word-wrap: break-word !important;">
      「接触即兴」从自己出发，与他人连结。过程中，细细聆听身体所感知的所有讯息，透过自己的身体不断接收与反应对方的身体，时时刻刻，意识将无法出走，身心于是合一。
     </span>
    </p>
    <p style="max-width: 100%;min-height: 1em;box-sizing: border-box !important;word-wrap: break-word !important;">
     1992
     <span style="max-width: 100%;font-family: 宋体;box-sizing: border-box !important;word-wrap: break-word !important;">
      年，古名伸由美国回到台湾。她想要找人跟她一起跳舞，于是开始散播「接触即兴」的种子，到处收集人跟她跳舞。慢慢的，来跳舞的人越来越多，没想到，「接触即兴」竟成为了一个悄悄在改变台湾舞蹈面貌的身体训练。在这个过程中，人越来越聚集，在舞蹈里面发现了自己，找到了彼此。我们在这个舞蹈里面成长，除了学会了怎么样跳舞之外，更学会了如何在这个世界里自处，也学会了怎么过日子，看人生。
     </span>
    </p>
    <p style="max-width: 100%;min-height: 1em;box-sizing: border-box !important;word-wrap: break-word !important;">
     1993
     <span style="max-width: 100%;font-family: 宋体;box-sizing: border-box !important;word-wrap: break-word !important;">
      年「古名伸舞团」成立，开始做编创发表和即兴舞蹈的推广。由于「接触即兴」特殊的吸引力，舞团成员向心力超强，逐渐形成个个都是艺术家但又是一个大整体的特色于是更名为「古舞团」，以示团风。
     </span>
    </p>
    <p style="max-width: 100%;min-height: 1em;box-sizing: border-box !important;word-wrap: break-word !important;">
     <span class="Apple-converted-space">
     </span>
     <span style="max-width: 100%;font-family: 宋体;box-sizing: border-box !important;word-wrap: break-word !important;">
      舞蹈是一种稍纵即逝的艺术，也难以用文字语言说得清楚。我们希望透过纪录片的形式，把一些珍贵的观念、历史、想法都留下来，让更多的人能够藉此了解「接触即兴」，这种特别又有机的舞蹈方式。
     </span>
    </p>
    <p style="max-width: 100%;min-height: 1em;box-sizing: border-box !important;word-wrap: break-word !important;">
     <span class="Apple-converted-space">
     </span>
     <span style="max-width: 100%;font-family: 宋体;box-sizing: border-box !important;word-wrap: break-word !important;">
      古舞团作为台湾「接触即兴」主要推广团体，有感于现存「接触即兴」知识无论文本着作或影像纪录多以英文为主，古舞团因此计划进行「接触即兴中文纪录片」制作与推广，以供华语地区的爱舞者参考。
     </span>
    </p>
    <p style="max-width: 100%;min-height: 1em;box-sizing: border-box !important;word-wrap: break-word !important;">
     25
     <span style="max-width: 100%;font-family: 宋体;box-sizing: border-box !important;word-wrap: break-word !important;">
      年来「接触即兴」在台湾的发展是由许许多多数不清志同道合的朋友一起耕耘出来的，可谓族繁不及备载。尽管有的离开了台湾，有的转换了跑道，有的一直默默支持，但这是一条有接力的长跑
