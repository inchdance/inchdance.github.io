     </span>

    <p style="margin: 0px;line-height: 18pt;">
     <span style="color: rgb(123, 12, 0);background-color: rgb(214, 214, 214);">
      <strong>
       <span px="px" rgb="rgb" sans-serif="sans-serif" style="margin: 0px;color: rgb(123, 12, 0);background-color: rgb(214, 214, 214);">
       </span>
      </strong>
      <span px="px" rgb="rgb" sans-serif="sans-serif" style="margin: 0px;color: rgb(123, 12, 0);background-color: rgb(214, 214, 214);">
       现代舞
      </span>
      <strong>
       <span px="px" rgb="rgb" sans-serif="sans-serif" style="margin: 0px;color: rgb(123, 12, 0);background-color: rgb(214, 214, 214);">
       </span>
      </strong>
     </span>
     <span px="px" rgb="rgb" sans-serif="sans-serif" style="margin: 0px;font-family: 宋体;font-size: 2px;">
      (
     </span>
     <span style="margin: 0px;color: rgb(214, 168, 65);font-family: 宋体;font-size: 12px;">
      （11/4开课，一期八堂课，期末将有呈现）
     </span>
     <span rgb="rgb" sans-serif="sans-serif" style="margin: 0px;">
      <br/>
     </span>
    </p>
    <p style="margin: 0px;line-height: 18pt;">
     <span style="margin: 0px;font-size: 14px;">
      「
      <strong>
       认识身体，感受，寻找关系再至时间、空间、精力的转变、动力与重量的运用与体会
      </strong>
      」
     </span>
    </p>
    <p style="margin: 0px;line-height: 18pt;">
     <span style="margin: 0px;font-size: 14px;">
      舞蹈是表现人的一种活生生的语言，它真实的表达人内在的情绪及意象并用身体直接地传达给他人。现代舞的诞生即是一种自我意识的兴起以及人回归自我的象征。随着大千世界的瞬息万变，现代舞到现今已是派别众多风格林立。在我们不断向外探讨如何动、如何舞亦或是你未曾接触过、了解过现代舞的同时，可否给
      <strong>
       自己和身体一段相处的时间
      </strong>
      ，将身体回到最初、更深一层的去了解与熟悉。
     </span>
     <br/>
    </p>
    <p style="margin: 0px;line-height: 18pt;">
     <span style="font-size: 14px;">
      萧瑀
     </span>
     <span style="margin: 0px;font-size: 14px;">
      将藉由
      <strong>
       动作组合
      </strong>
      的训练，强化肢体动作的
      <strong>
       延展性
      </strong>
      、
      <strong>
       灵敏度
      </strong>
      并搭配不同高度的综合练习开启身体更深一层的
      <strong>
       感知
      </strong>
      与
      <strong>
       多元
      </strong>
      的创造力。以现代舞的基础训练为根基将意识回归到身体本身，在运动的过程中同时关照、体会内在与外在空间的相互关系，并用一种不同的身体运行方式去重新认识自己。另外将综合动作形成的三大元素「时间、空间、精力」以舞蹈小品的形式训练及呈现，藉以此训练方式让动作如实地运用在各种不同型态的舞蹈变化之中外，同时训练个人对于舞蹈风格及表现力的展现。
     </span>
    </p>
    <p style="margin: 0px;line-height: 18pt;">
     <span lang="ZH-CN" sans-serif="sans-serif" style="margin: 0px;">
      <br/>
     </span>
    </p>
    <p style="margin: 0px;line-height: 18pt;">
     <span style="margin: 0px;color: rgb(123, 12, 0);background-color: rgb(214, 214, 214);">
      身体开发
      <strong>
      </strong>
     </span>
     <span style="margin: 0px;padding: 0px;text-align: left;color: rgb(214, 168, 65);text-transform: none;text-indent: 0px;letter-spacing: normal;font-family: 宋体;font-size: 12px;font-style: normal;font-variant: normal;font-weight: 400;text-decoration: none;word-spacing: 0px;orphans: 2;-webkit-text-stroke-width: 0px;">
      （11/7开课，一期八堂课，期末将有呈现）
     </span>
    </p>
    <p style="margin: 0px;line-height: 18pt;">
     <span lang="EN-US" sans-serif="sans-serif" style="margin: 0px;">
     </span>
    </p>
    <p style="margin: 0px;line-height: 18pt;">
     <span style="margin: 0px;font-size: 14px;">
      我们每天使用着我们的身体，不管眼前的工作和生活，还是诗和远方的爱好，都需要身体来承载。偶尔，有时候，觉得身体有点不那么够用，不那么灵便灵活听使唤，或者不知道怎样能更好用更有趣，又或者只是渴望有地方可以撒撒野活动身体……
     </span>
    </p>
    <p style="margin: 0px;line-height: 18pt;">
     <span style="margin: 0px;font-size: 14px;">
      那么也许，是时候我们来开发一下身体呢。
     </span>
    </p>
    <p style="margin: 0px;line-height: 18pt;">
     <span style="font-size: 14px;">
      <strong>
       <span px="px" sans-serif="sans-serif" style="margin: 0px;font-size: 14px;">
        身体开发
       </span>
      </strong>
      <span px="px" sans-serif="sans-serif" style="margin: 0px;font-size: 14px;">
       需要你的：
       <strong>
        一点勇气，一点耐心，一点体力，一点想象力和大量的好奇心
       </strong>
       。
      </span>
     </span>
    </p>
    <p style="margin: 0px;line-height: 18pt;">
     <span style="margin: 0px;font-size: 14px;">
      飞行家的身体开发工作坊是一个系列的课程，
      <strong>
       综合即兴舞蹈
      </strong>
      、
      <strong>
       武术
      </strong>
      、
      <strong>
       身体剧场
      </strong>
      等元素，进行身体开发训练，不断扩展身体可能性的边界。
     </span>
    </p>
    <p style="margin: 0px;line-height: 18pt;">
     <span style="margin: 0px;font-size: 14px;">
      这一系列的工作坊将循序渐进逐步深入的进行，每次工作坊都将包括以下方面：
     </span>
    </p>
    <p style="margin: 0px;line-height: 18pt;">
     <span style="margin: 0px;font-size: 14px;">
      身体基础训练：找到自己身体的结构和节奏，在动作中使用呼吸和势能。
     </span>
    </p>
    <p style="margin: 0px;line-height: 18pt;">
     <span style="margin: 0px;font-size: 14px;">
      想象力是第一生产力：
      <strong>
       空间
      </strong>
      ，
      <strong>
       时间
      </strong>
      ，
      <strong>
       变身
      </strong>
      ……
      <strong>
       想象力
      </strong>
      可以帮助我们打开身体的新世界。
     </span>
    </p>
    <p style="margin: 0px;line-height: 18pt;">
     <span style="margin: 0px;font-size: 14px;">
      任务和创作：开发身体完成叠加复杂任务的能力，用身体进行创作和合作。
      <br/>
     </span>
    </p>
    <p style="margin: 0px;line-height: 18pt;">
