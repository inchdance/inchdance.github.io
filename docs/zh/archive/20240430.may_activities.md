     <section style="">
      <grammarly-extension style="top: 0px;left: 0px;pointer-events: none;">

      <section style="font-size: 14px;line-height: 1.75;">
       <p style="text-align: center;text-wrap: wrap;">
        <strong>
         <br/>
        </strong>
       </p>
       <p style="text-align: center;text-wrap: wrap;">
        <span style="font-size: 16px;">
         <strong>
          流动中的动量
         </strong>
        </span>
        <br/>
       </p>
       <p style="text-align: center;text-wrap: wrap;">
        <strong>
         The Flow of Momentum
        </strong>
       </p>
       <p style="text-align: center;text-wrap: wrap;">
        <br/>
       </p>
       <p style="text-wrap: wrap;">
        如果接触即兴是身体的对话，那么物理法则就是这种语言背后的语法。物理限制了物质和能量的基本作用，但也使身体间的对话变得有序和能被理解。
       </p>
       <p style="text-wrap: wrap;">
        <br/>
       </p>
       <p style="text-wrap: wrap;">
        5月想和大家共同探索接触即兴中的
        <strong>
         「动量」（Momentum），从物理的角度，来理解身体和运动：在这里我们不讨论玄学的能量感受，而是回归到能量原本的定义：动能、重力势能，或是热能，一个物理学的概念。
        </strong>
       </p>
       <p style="text-wrap: wrap;">
        <br/>
       </p>
       <p style="text-wrap: wrap;">
        比如从矢量的角度来理解「动量」，从「动量守恒」的角度理解「碰撞」。比如从投影的角度具象化地观察「重心」。从重心的投影落在了凸包（Convex）之外这样的角度来理解「失去平衡」。
       </p>
       <p style="text-wrap: wrap;">
        <br/>
       </p>
       <p style="text-wrap: wrap;">
        而在接触即兴中，更为人所熟知的与动量相关的动作练习，包括基础的托举和支撑，乃至难度更大的飞翔和落地，都需要借助动量的流动，得以更轻松的实现。
       </p>
       <p style="text-wrap: wrap;">
        <br/>
       </p>
       <p style="text-wrap: wrap;">
        我会从物理学的角度带领大家一起感受什么是失重，什么是轻盈，什么是聆听，什么是跟随？而连续三次的课程设计，也会根据大家的参与情况而逐渐深入。
       </p>
       <p style="text-wrap: wrap;">
        <br/>
       </p>
       <p style="text-wrap: wrap;">
        身体的练习有很多条路，每条路上都带有不同的视角，我并不会说物理学是一种更本质，或者更深刻的视角，但至少是一个更为纯粹的、同时也有意思的视角，是每一位身体练习者值得花时间来琢磨、来体验的视角。而且我们在地球上跳舞，总归还是归牛顿（的重力）管的，偶尔唤醒一下死去的高中物理的记忆也不错。
       </p>
       <p style="text-align: center;text-wrap: wrap;">
        <strong>
         <br/>
        </strong>
       </p>
       <p style="text-wrap: wrap;">
        <span style="text-decoration: underline;">
         <strong>
          5月12日 主题「亲近地面」：
         </strong>
        </span>
       </p>
       <p style="text-wrap: wrap;">
        探索对重心的觉察，和动量在低空中的流动。滚动、滑动和翻滚练习，熟悉在低空中做支撑和动作发展。
       </p>
       <p style="text-wrap: wrap;">
        <br/>
       </p>
       <p style="text-wrap: wrap;">
        <span style="text-decoration: underline;">
         <strong>
          5月19日 主题「流动的重心」：
         </strong>
        </span>
       </p>
       <p style="text-wrap: wrap;">
        从单人的重心变化，过渡到双人之间的力量平衡（Counterbalance），并发展至更多人参与的结构。也会挑战失重边缘的动作发展。
       </p>
       <p style="text-wrap: wrap;">
        <br/>
       </p>
       <p style="text-wrap: wrap;">
        <span style="text-decoration: underline;">
         <strong>
          5月26日 主题「动量的冒险」:
         </strong>
        </span>
       </p>
       <p style="text-wrap: wrap;">
        尝试更有动量和加速度支撑的练习，包括坠落、反弹、同时试着把自己抛出去，突破平衡状态下的舒适，同时另失控也变得更有觉知。建议参加了前两次课的伙伴报名。
       </p>
