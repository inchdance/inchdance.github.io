      <section style="text-wrap: wrap;line-height: 1.75em;">
       <a data-itemshowtype="0" data-linktype="2" href="http://mp.weixin.qq.com/s?__biz=Mzg5ODgyODc2Ng==&amp;mid=2247491678&amp;idx=2&amp;sn=c82e2fa35c2e4051360513f6a2a7188e&amp;chksm=c05e30eff729b9f9d6b6601520d25f038d17af0b6629aa01cbda85c6e815b9cfa81eb550c60e&amp;scene=21#wechat_redirect" imgdata="null" imgurl="" linktype="text" tab="innerlink" target="_blank" textvalue="作为身心学的太极拳——谈谈为何而练">
        作为身心学的太极拳——谈谈为何而练
       </a>
       <br/>
      </section>
      <section style="text-wrap: wrap;line-height: 1.75em;">
       <br/>
      </section>
      <section style="text-wrap: wrap;line-height: 1.75em;">
       <span style="font-size: 14px;">
        太极系列课推出以后，有外地的朋友来问，能不能开一个工作坊，用2-3天的时间把内容学完，这样不是能更方便外地的朋友门安排时间么？
       </span>
       <br/>
      </section>
      <section style="text-wrap: wrap;line-height: 1.75em;">
       <span style="font-size: 14px;">
        我们考虑再三，还是遗憾拒绝了。
       </span>
      </section>
      <section style="text-wrap: wrap;line-height: 1.75em;">
       <span style="font-size: 14px;">
        <br/>
       </span>
      </section>
      <section style="text-wrap: wrap;line-height: 1.75em;">
       <span style="font-size: 14px;">
        如同所有的身心学，太极的学习，不可避免地必须经历一段漫长的学习曲线。虽然从外表看起来只是一招一式，然而其中却融合着精细的呼吸、气的流转、乃至每一个手势和脚步，都需要精密的协调和感受。而在这其中的发展，并不能一蹴而就。
       </span>
      </section>
      <section style="text-wrap: wrap;line-height: 1.75em;">
       <span style="font-size: 14px;">
        <br/>
       </span>
      </section>
      <section style="text-wrap: wrap;line-height: 1.75em;">
       <span style="font-size: 14px;">
        在太极的学习中，我们最怕看到的，便是大家在课堂上觉得自己已经学会了这个动作，回家以后就疏于练习了。
       </span>
       <span style="font-size: 14px;letter-spacing: 0.034em;">
        太极的精华是需要时间来逐渐领悟的，我们希望通过持续性的系列课程，陪伴大家度过这个学习曲线，逐渐进入太极之精微。
       </span>
      </section>
      <section style="text-wrap: wrap;line-height: 1.75em;">
       <span style="font-size: 14px;">
        <br/>
       </span>
      </section>
      <section style="text-wrap: wrap;line-height: 1.75em;">
       <span style="font-size: 14px;">
        从第一期太极系列课开课之际，我们便开始了每周一到周五早上半个小时的线上站桩，以每天半小时的微小动力陪伴大家持续的前进。
       </span>
      </section>
      <section style="text-wrap: wrap;line-height: 1.75em;">
       <span style="font-size: 14px;">
        <br/>
       </span>
      </section>
      <section style="text-wrap: wrap;line-height: 1.75em;">
       <span style="font-size: 14px;">
        目前我们决定，将这个站桩群也向非系列课的朋友们开放，
       </span>
      </section>
      <section style="text-wrap: wrap;line-height: 1.75em;">
       <span style="font-size: 14px;">
        <br/>
       </span>
      </section>
      <section style="text-wrap: wrap;line-height: 1.75em;">
       <span style="font-size: 14px;">
        对于一些还在对系列课观望，或者身不在上海无法参加系列课的朋友，都可以通过这样的尝试来感受太极练习带给你的细微体验。
       </span>
      </section>
     </section>
