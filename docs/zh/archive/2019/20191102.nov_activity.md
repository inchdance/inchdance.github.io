     <p>
      <span style="font-size: 13px;">
       秋天是身体新陈代谢开始调整的季节，皮肤好像变得比较干燥，人也变得慵懒准备休息与过冬。入秋后因为代谢缓慢与身体正在与节气互相调节的关系，常常做任何事都力不从心，脾气也因此受影响。
      </span>
     </p>
     <p>
      <span style="font-size: 13px;">
       这种时候放慢脚步，给自己多点的时间与空间观看一下周遭，让自己身心合一，也许就会再度回到最佳状态，很多事情也随之放下。
      </span>
     </p>
     <p>
      <span style="font-size: 13px;">
       <br/>
      </span>

      <span style="font-size: 13px;">
       在放慢脚步的时刻来一段与自己的小舞蹈，感觉是再适合不过的。
      </span>
     </p>

     <p>
      <span style="font-size: 14px;">
       站立
       <br/>
      </span>
     </p>
     <p>
      <span style="font-size: 14px;">
       让你的臀部变重，
       <br/>
       放松内部器官。入骨盆。
       <br/>
       自然地呼吸
       <br/>
       感受你手臂的重量
       <br/>
       感受脊椎穿过肩部直至向上支撑头骨。
       <br/>
       以此为中心站立，你将观察到一些小的动作
       <br/>
       我称之为“小舞蹈”。
       <br/>
       这似乎是一种反射性动作，尤其是关节周围，即使你很放松也能保持直立。
       <br/>
       你可以去倒下，但不是现在。
      </span>
     </p>
     <p>
      <span style="font-size: 14px;">
       你内观自己的站姿
       <br/>
       自然地呼吸
      </span>
     </p>
     <p>
      <span style="font-size: 14px;">
       肩胛骨沉重，臀骨沉重
       <br/>
       感受呼吸
       <br/>
       让内脏沉入骨盆，让脊椎骨向上支撑头骨。
       <br/>
       在手臂垂下的方向，不要改变那个方向，做你能感觉到的最小的伸展。
      </span>
      <br/>
     </p>

      <span style="font-size: 14px;">
       释放它
       <br/>
       再试一次
       <br/>
       它可以变得更小吗？
       <br/>
       初始的伸展
       <br/>
       释放它
       <br/>
       再来一次
       <br/>
      </span>
     </p>
     <p>
      <span style="font-size: 14px;">
       在手臂垂下的方向，不要改变那个方向，做你能感觉到的最小的伸展。
       <br/>
       能再小点儿吗？
      </span>
      <br/>
      <br/>
      <span style="font-size: 14px;">
       想象它穿透你的指纹，经过指尖
       <br/>
       那么，如果这就是它的运动方向，那么你是从哪里开始拉伸的呢?手臂?或肩膀?
       <br/>
       <br/>
       记住这个感觉。
      </span>
     </p>
     <p>
      <span style="font-size: 14px;">
       从尾骨向上，
       <br/>
       骶骨，
       <br/>
       腰部，
       <br/>
       胸腔，
       <br/>
       颈椎，
       <br/>
       延伸向上至寰椎（脊柱顶端，与枕骨相连）
       <br/>
       在两耳之间，做你能感受到的最小的拉伸
      </span>

       <br/>
       再来一次
       <br/>
       还可以再小点儿吗？

     <p>
      <span style="font-size: 14px;">
       想象，但不要做。
       <br/>
       想象你正要用右脚迈出一步。有什么不同吗？
       <br/>
       <br/>
       回到中立，
       <br/>
       站立，
       <br/>
       小舞蹈，
      </span>

     <p>
      <span style="font-size: 14px;">
       想象，但不要做。
       <br/>

      </span>

       左，右，左，右，左，右，左，右

       <br/>

       <br/>
       自然地呼吸，
       <br/>
       感受横膈膜的移动。

       <br/>
       放松器官沉入盆骨。
       <br/>
       稍事休息。
