     <span style="color: rgb(136, 136, 136);font-size: 14px;">
      学习接触即兴15个月带给我很多愉悦和变化，这些变化由內而外，外人看到说我变得年轻美丽，我自己则越来越多被CI的探索无限可能所吸引，跳得停不下来。原来我可是一个不太喜欢运动的人，每每奔着现实想要苗条和健康的目标下决心运动，实际从运动过程中大脑收到的信息是逼迫，累，苦，熬，这些不愉快的信息让我体会不到运动的快乐，所以几乎都是虎头蛇尾，最后不了了之。接触即兴的学习和练习一路走来，感受身体，不断聆听，我对身体的意识在苏醒和增加。说说最近的变化，聆听的意识，从和伙伴共舞慢慢扩展到个人练习的时候，我感觉逐步开启了和自己身体的对话，体察身体细小部位的感觉，慢慢启动她们，尝试反复地或者用不同的方式动起来，这个过程是对话也是和身体的游戏，专注，投入，细致，有趣！这些让我和身体的连接不断增加，更多地了解她认识她，从而更丰富地运用她，调节她，发展她！

     <span style="color: rgb(136, 136, 136);font-size: 14px;">
      我从舞蹈中获得了很大的益处。这益处和进步正由舞蹈慢慢的进入到了我的生活。现在的我，加班再忙，也不会觉得很累了，因为我学会了感受和调节，因为我的心更加宽了。不知怎么回事，最近感觉自己的舞蹈退步了，好像舞蹈生活和工作生活也会互相影响，就像冷水和热水，加在一起就成了温水，觉得这也挺好。一切顺其自然，也许到某个时刻，我也专心致志当下，放掉犹疑和彷徨，那时我就修成正果了。昨天的舞酱接触了很多新的身体，越多的交流发现越多的层次与空间。一个人跳时，最美的时刻的是真正放下头脑，去让身体自己去表达自己的意志，尽管就这都很难；而和他人在一起跳时，又完全是一个全新的领域，真正的自我都可以在舞蹈中体现，闪过的感性、性感、性、情绪、情感、自恋、自卑、断断续续的介入与不太成功的呼应、防御…我想理想的状态是感受的同时忘记感受，彼此内在的真正同一。2018开始打开伪装，希望2019更好些，尽管这个世界越来越复杂，我还是有点向往简单。

    <p style="line-height: 24px;">
     <span style="color: rgb(136, 136, 136);font-size: 14px;">
      2018年的接触即兴，对我来说是关于动中觉知与关系。
     </span>
    </p>
    <p style="line-height: 24px;">
     <span style="color: rgb(136, 136, 136);font-size: 14px;">
      打开自己去跳舞，刚开始不容易，但逐渐都是可以的，因为我们身体的本身存在的本身就会舞蹈，只要我们愿意与身体连接。而在接触即兴这样一种自由单纯而又充满刺激变化的形式中，创造和自发性会不断地被激发出来。
     </span>
    </p>
    <p style="line-height: 24px;">
     <span style="color: rgb(136, 136, 136);font-size: 14px;">
      再走下去，就开始看见了巨大的习性怎样在每一个动的时间中影响着自己与关系。于是，对身体有了更大的好奇和探索，也开始深入身心学更多的补充领域去学习。
     </span>
    </p>
    <p style="line-height: 24px;">
     <span style="color: rgb(136, 136, 136);font-size: 14px;">
      而对我启发最大的一个点是关于行动中的空隙，仿佛发现了一个巨大的宝库，从空隙中找到不为第一反应所困的更多可能性，这让我瞬间在关系中能感受到和享受更多的自由了。也能够看到更多关系的层次，首先会看到整个空间，再慢慢进入自己和他人，在这样一个神奇的场域中，让自己被深深的滋养着和蜕变着。

     <span style="color: rgb(136, 136, 136);font-size: 14px;">
      回想起来，无论夏日骄阳如火，还是冬天冷雨绵绵，无论身体心灵是轻松愉悦，而是疲倦困顿，都会在周中的某个晚上和周末的某个下午，走在一条去跳舞的路上。去时的心情不尽相同，有时容易，有时艰难，有时轻快，有时踟蹰，但回来的时候总是神清气爽，积聚了新的能量。

    <p style="margin-bottom:.1px;text-align:justify;">
     <span style="color: rgb(136, 136, 136);font-size: 14px;">
      有时跳完舞会记下一些句子。有次在回家路上，写下了这样一句——“我像一条找到了水的鱼”，这自然就冒出来的一句，现在仍然很喜欢，大概是因为成年人的生活大多数时候都像一条脱离了一湖好水的鱼吧。又翻了翻以前记下的一些文字，看到这些记录时，当时的心情又会浮现出来。

      #是一种慢慢开始说话的感觉，之前好像没有声音，或者只是一些无意识的声音，现在慢慢开始说出一些单词。以前是一种混沌的互动，现在开始有了一些语词的交流。以前是在沉睡中跳舞，现在是慢慢醒过来跳舞。在接触即兴中人是会逐渐进化吧，Nancy跳了四十多年，她进化到了什么状态？
     </span>
     <br/>
    </p>
    <p style="margin-bottom:.1px;text-align:justify;">
     <span style="color: rgb(136, 136, 136);font-size: 14px;">
      #并不是每段舞都好。有时很好，有时不那么好。有时跟一个人跳感觉很默契有趣，下次再跟同一个人跳时反而处处不顺。有时跟一个完全陌生的人跳感觉很好，第二次再跟TA跳时再也找不到第一次的感觉。然而这是多么正常啊！
     </span>
     <br/>
    </p>
    <p style="margin-bottom:.1px;text-align:justify;">
     <span style="color: rgb(136, 136, 136);font-size: 14px;">
      #有一天不在状态，是因为新的老师，新的语言，新的音乐，新的人，太多因素让我有点无所适从。另一天不在状态，却是因为太过熟悉，熟悉的环境，熟悉的人，熟悉的动作。从复杂中找到稳定，从熟悉中找到新鲜。

     <span style="color: rgb(136, 136, 136);font-size: 14px;">
      #最近发现一个现象，关于接触即兴，大家说得少了，活动结束时也不说，群里也不说，只是定期来跳舞。相比开始时地很多“关于接触即兴的”交流，现在进入了一种无言。然而这不是热情消退了，内心的火越旺时，反而显得安静了。如果身体已经说了那么多，体验到那么多丰富而微妙的变化和愉悦，就会觉得说话有点乏力。不是不想说，而是一句话说出来后马上就觉得并没说出想说的东西，甚至有点破坏了某些东西。所以就安于这沉默吧，安于这沉默，等待……

     <span style="color: rgb(136, 136, 136);font-size: 14px;">
      #对方还有多少可能？TA的能力还有多少没用出来？彼此的支撑还有什么可能？我们的组合还能有什么样的变化？我发现这是最近会去尝试的一个意图，温和地挑战一下。“我来跟你打一架”，一位搭档如是说。嗯，有时候确实很需要打一架。相互挑战和支持奇妙地结合在一起，兴味盎然。

      一年又过去了，留下了许多美好回忆。当说到“美好”这个词时，我们说的不是这个词，而是意指那些它所标记的真切经历。我想一起跳过舞，一起喝过酒、唱过歌的人知道我在说什么。这种回忆让人感怀，想起来就会让人感到温暖和愉悦。

     <span style="color: rgb(136, 136, 136);font-size: 14px;">
      “来什么接什么” 有时你跟人跳的时候他没有像你想的那样动，没关系，那就跟着他，跳着跳着又会发生变化，你开始带动，主动被动变得不那么明显，跟着流动就都不会累~每次跳接触即兴都开心，身体每个部位都滚动过了或是被压过了，心像是更开了一样~持续跟着小伙伴跳了两年多，我的身体越来越舒展自如，我们的灵魂摄影师小勺也发现了我的脸和身体很舒展，照片不会撒谎。我感受到不同的人带来不同的能量和流动~今天来的一个外国男孩居然蹲着站起来硬扛起了我~越信任放松越安全轻松~人和人打交道不就是这样吗？

      兵

    <p style="line-height: 24px;">
     <span style="color: rgb(136, 136, 136);font-size: 14px;">
      第一次听说CI，就觉得自己一定会喜欢。也没有什么特别的理由，只是凭着直觉就知道自己会喜欢。
     </span>
    </p>
    <p style="line-height: 24px;">
     <span style="color: rgb(136, 136, 136);font-size: 14px;">
      第一次舞酱体验我还记得 Zoe 问我们每个人的能量有多高，我伸手举过了头顶，满满的能量。开始常常来跳了之后，慢慢地感觉到自己变得柔软，变得敏锐，也对自己的身体有了更多的认识。记得有一次跳着跳着，躺在地上，看着自己的肌肉随着手指的轻轻敲动而波动，竟然感动得哭了。还有一次，和伙伴一起跳舞，竟然感觉到灵魂出窍一般地同频同步，最后静静地拥抱了很久，很感动。
     </span>
    </p>
    <p style="line-height: 24px;">
     <span style="color: rgb(136, 136, 136);font-size: 14px;">
      跳舞的时候，我不太很喜欢嘈杂的音乐，也不太喜欢和很多人一起狂欢式地蹦，所以那样的时候，我会不管音乐，自顾自地慢慢跳，好在，这里是接触即兴，没有人会指责我不合群，更没有人强迫我去嗨。我就这么安静地慢慢跳，有时候还会有小伙伴还加入我一起在嗨嗨的音乐下慢慢地跳，很开心。
     </span>
