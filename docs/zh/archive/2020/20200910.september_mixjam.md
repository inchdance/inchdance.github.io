      <span style="font-size: 14px;">
       “混”在于开拓身体训练的多元性，而“酱”来源于舞酱（jam），享受不同肢体碰撞的风味。
      </span>
      从这个月开始，我们将围绕接触即兴和其他训练或学科的关联性，
      <strong style="font-size: 14px;white-space: normal;">

      <strong>
       9月份的主题是接触即兴和东方身体智慧。
      </strong>
      而接触即兴起源于70年代初的美国，创始人
     </span>
     <span style='font-family: mp-quote, -apple-system-font, BlinkMacSystemFont, "Helvetica Neue", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei UI", "Microsoft YaHei", Arial, sans-serif;font-size: 14px;'>
      史提夫·帕克斯顿（Steve Paxton）从日本合气道和太极等不同运动体系汲取养分，慢慢在探索中形成接触即兴身体的训练技巧。
      <br/>
      <br/>
     </span>
    </p>
    <p style="text-align: left;">
     <strong style='font-family: mp-quote, -apple-system-font, BlinkMacSystemFont, "Helvetica Neue", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei UI", "Microsoft YaHei", Arial, sans-serif;'>
      <span style="font-size: 14px;">
       如何落地不容易受伤呢？
      </span>
     </strong>
     <span style='font-family: mp-quote, -apple-system-font, BlinkMacSystemFont, "Helvetica Neue", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei UI", "Microsoft YaHei", Arial, sans-serif;font-size: 14px;'>
      借鉴合气道的滚地法，通过翻滚拉长落地路径进行缓冲，而非把重量一下子卸到地板上。
      <strong>
       如何使肢体和当下产生更强的连接？
      </strong>
      借鉴太极推手，在接触中感受能量的流动，并把它源源不断地注入到即兴舞蹈中。
      <br/>
      <br/>
     </span>

      接触即兴落脚台湾二十五年，影响了台湾现代舞的样貌。
     </span>
     <span style='font-family: mp-quote, -apple-system-font, BlinkMacSystemFont, "Helvetica Neue", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei UI", "Microsoft YaHei", Arial, sans-serif;font-size: 14px;text-align: justify;'>

      内含二十五年来，接触即兴在台湾的重要历史镜头，包含工作坊、身体训练以及实践者访谈等。

    <p style="text-align: left;">
     <span style="font-size: 14px;">
      太极拳是先通过拳架
      <strong>
       了解自己，先求知己，再论知人
      </strong>
      。这个与接触即兴（以接触为中心的互动）正好形成了一种平衡。
     </span>
    </p>
    <p style="text-align: left;">
     <br/>
    </p>
    <p style="text-align: left;">
     <span style="font-size: 14px;">
      在上次教学的无极桩基础上，这次站桩将练习
      <strong>
       混元桩
      </strong>
      。站桩时曲肘抬臂，两手像抱着一个球，屈膝下蹲，重心下降而且保持稳定，进入了上虚下实的状态。这是太极拳内功的入门功法，注重外静内动，是一种静功。长期练习可使自身腿部根基更稳，日后练习太极拳可以得心应手。
     </span>
    </p>
    <p style="text-align: left;">
     <br/>
    </p>
    <p style="text-align: left;">
     <span style="font-size: 14px;">
      在拳法上，我们将复习
      <strong>
       陈氏太极拳第一式金刚捣锥
      </strong>
      。“金刚”一词源自梵语，是金中最刚之意。此势右手捏拳如杵之势，左手曲如臼之形，右拳落于左手心中，如石杵捣锥，此为象形取义。在一个招式里，劲有八法，步有五型，具备了太极拳招式的所有特点。
      <span style='font-family: mp-quote, -apple-system-font, BlinkMacSystemFont, "Helvetica Neue", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei UI", "Microsoft YaHei", Arial, sans-serif;'>
       太极套路的动作让身体进入一种陌生的姿态，重新与身体建立连接。而重复的练习中发现更丰富的感知，并通过身法上的要求提醒我们回到中正放松的状态。
       <strong>
        当身体回到松正状态时，我们的心也相应产生了变化
       </strong>
       。
      </span>
     </span>

    <p style="text-align: left;">
     <span style="font-size: 14px;">
      合气道中有一类技法叫做呼吸法，呼吸法并不是调息也不是对呼吸的觉知，更不是屏息，而是
      <strong>
       借由呼吸来配合身体的动作
      </strong>
      ，吸气上升将重心抬起，呼气落下，稳定而又有力，一呼一吸之间把力量释放出来，没有多余的动作，也不浪费一点体力，干净利落。在接触即兴中，我们经常只看到动作而忘记了呼吸，这一次，试着融入呼吸的力量。
      <br/>
     </span>
    </p>
    <p style="text-align: left;">
     <br/>
    </p>
    <p style="text-align: left;">
     <span style="font-size: 14px;">
      <span style='font-family: mp-quote, -apple-system-font, BlinkMacSystemFont, "Helvetica Neue", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei UI", "Microsoft YaHei", Arial, sans-serif;'>
       在热身阶段，我们会继续巩固
      </span>
      <strong>
       <span style='font-family: mp-quote, -apple-system-font, BlinkMacSystemFont, "Helvetica Neue", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei UI", "Microsoft YaHei", Arial, sans-serif;'>
        合气道的滚地
       </span>
      </strong>
      <span style='font-family: mp-quote, -apple-system-font, BlinkMacSystemFont, "Helvetica Neue", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei UI", "Microsoft YaHei", Arial, sans-serif;'>
       ，也就是“受身”。当我们被对手摔倒或是自己倒地时，搭建好滚翻路径，使身体平缓滚落到地面，从而减轻自身所受到的冲击力达到自我保护的作用。

      不同的呼吸模式和节奏会极大改变人的身心状态，比如恐惧时气息会停滞，愤怒时胸腔起伏呼吸。
