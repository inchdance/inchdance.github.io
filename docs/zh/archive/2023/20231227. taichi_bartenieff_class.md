          <p style="margin-bottom: 0px;letter-spacing: 0.578px;text-wrap: wrap;background-color: rgb(245, 245, 245);">
           <span style="color: rgb(0, 0, 0);font-family: DengXian;font-size: 14px;letter-spacing: normal;text-align: start;">
            如何在
           </span>
           <span style="color: rgb(0, 0, 0);font-family: DengXian;font-size: 14px;letter-spacing: normal;text-align: start;">
            这个
           </span>
           <span style="color: rgb(0, 0, 0);font-family: DengXian;font-size: 14px;letter-spacing: normal;text-align: start;">

           </span>

            着陆
           </span>
           <span style="color: rgb(0, 0, 0);font-family: DengXian;font-size: 14px;letter-spacing: normal;text-align: start;">
            ？

           <span style="font-size: 10.5pt;color: rgb(0, 0, 0);letter-spacing: normal;text-align: start;font-family: DengXian;">
            对我来说，练习太极的意义最重要的不是要用太极来做什么，而是通过练习它让我的身心不断回到中正安舒的状态，既保持扎根，又保有灵活，以此作为基础行走在这个世界上。我觉得这也是很多现代人所需要的。
           </span>
          </p>
          <p style="margin-bottom: 0px;letter-spacing: 0.578px;text-wrap: wrap;background-color: rgb(245, 245, 245);">
           <span style="font-size: 10.5pt;color: rgb(0, 0, 0);letter-spacing: normal;text-align: start;font-family: DengXian;">
            <br/>
           </span>
          </p>
          <p style="font-size: 14px;text-wrap: wrap;">
           对于现代都市人来说，太极拳是一种极为适合的练习方式，它是中国流传已久的身心学，符合现代身心学的诸多定义，而且提供了完备的日常练习方法，真正进去之后会感到无穷无尽的乐趣。而作为中国人，我们理解太极有着天然的优势，它本身就是用我们的语言来讲述的一个东西，我们更容易进入它。譬如拳谱中所云「若问体用何为准，意气君来骨肉臣」，这句话对
           <span style="font-size: 14px;letter-spacing: 0.578px;text-wrap: wrap;background-color: rgb(245, 245, 245);">
            我们来说
           </span>
           <span style="font-size: 14px;letter-spacing: 0.578px;text-wrap: wrap;background-color: rgb(245, 245, 245);">
            一点都不难
           </span>
           <span style="font-size: 14px;letter-spacing: 0.578px;text-wrap: wrap;background-color: rgb(245, 245, 245);">
            ，但如何
           </span>
           向国外的朋友解释这句话的意思，我发现非常困难。
          </p>
          <p style="font-size: 14px;text-wrap: wrap;">
           <br/>
          </p>
          <p style="font-size: 14px;text-wrap: wrap;">
           在之前的活动中有伙伴问到「能不能有一种相对来说更快的方式进入太极」？如果将这个问题，与速成的想法区分开来的的话，是一个合理的好问题。我认为正是在这里，西方的身心学可以有很大的帮助，它能够帮助我们用更容易理解的语言来体会太极。同时身心学（这里主要指巴特尼夫基本动作，也包括BMC等其它相关体系）中所提供的思想和练习，也有助于增加我们对自己身体的觉知，从而更容易感受到太极拳谱中所说的那些相对凝练且玄妙，但却让人感到难以领会到的东西。就我个人的体验而言，身心学的学习为我的太极练习提供了很大的助力，而其中最重要的，也许是它让我
           <strong>
            感受到
           </strong>
           <strong>
            练习的丰富性，让太极练习本身成为一种享受，使它成为一件我愿意经常去做的事情，而其练习也自然地推动了我在其它方面的进步。
           </strong>
           这样就形成了正向循环。我想太极和身心学的结合也同样会对其他参与者产生同样的效果。
          </p>
