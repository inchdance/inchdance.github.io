        <strong>
         <span style="font-size: 14px;">
          什么是Voguing?
         </span>
        </strong>
       </span>
      </section>
      <section style="margin-bottom: 0px;padding-right: 20px;padding-left: 20px;letter-spacing: 1px;font-size: 16px;line-height: 1.75em;">
       <span style="font-size: 14px;letter-spacing: 1px;">
        Voguing，一种高度风格化、现代的House舞蹈。这种舞蹈风格在1960年代早期到1980年代由非裔和拉丁裔等性少数群体在美国纽约哈林区的舞厅里问世。它受到《Vogue》杂志和古埃及象形文字的图案的灵感启发，以表演模特儿所摆姿势创出舞姿。主要重点是在手的动作，以旋转为主，还有招牌的动作Dip。这种舞蹈在1990年歌手麦当娜Madonna的歌曲《Vogue》及其音乐录影带，和1990年纪录片《巴黎在燃烧》得到了主流曝光。
       </span>
      </section>
      <section style="white-space: normal;letter-spacing: 1px;padding-right: 20px;padding-left: 20px;font-size: 16px;text-align: right;line-height: 1.75em;">

        ——摘自维基百科Wikipedia
       </span>

        <strong style="font-size: 16px;letter-spacing: 1px;text-wrap: wrap;">
         <span style="font-size: 14px;">
          什么是Ballroom文化?
         </span>
        </strong>
       </span>
       <br/>
      </section>
      <section style="white-space: normal;letter-spacing: 1px;padding-right: 20px;padding-left: 20px;text-align: left;line-height: 1.75em;">
       <span style="font-size: 14px;">
        <span style="font-size: 14px;">
         Ballroom文化起源并发展与20世纪中后期的美国纽约哈林区。（这同时也是黑人平权、性少数平权、第二波女权主义等思潮和运动此起彼伏的时期）社群成员们大多受到阶层、性别、种族肤色等某方面或多方面的压力，这让他们处于社会歧视链的底端。
        </span>
        Ballroom文化的主要形式、实践、传承都依托于性别体系（Gender）、家族文化(House)以及舞会(Ball)。这种文化场景超越了通常意义下舞会的范围，人们在社群中受到庇护和教育，得到支持。
