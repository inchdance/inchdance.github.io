     <section powered-by="xiumi.us" style="font-size: 16px;line-height: 2;letter-spacing: 1px;padding-right: 10px;padding-left: 10px;">
      <p style="white-space: normal;">
       <span style="font-size: 14px;color: rgb(52, 44, 44);">
        那么巴特尼芙基本动作是什么？为什么将它与太极结合在一起？
       </span>
      </p>
      <p style="white-space: normal;">
       <span style="font-size: 14px;color: rgb(52, 44, 44);">
        <br/>
       </span>
      </p>
      <p style="white-space: normal;">
       <span style="font-size: 14px;color: rgb(52, 44, 44);">
        巴特尼芙基本动作（Bartenieff Fundamentals）是身心学*中的一个流派。
       </span>
       <span style='font-family: mp-quote, -apple-system-font, BlinkMacSystemFont, "Helvetica Neue", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei UI", "Microsoft YaHei", Arial, sans-serif;color: rgb(52, 44, 44);font-size: 14px;'>
        创始人伊姆嘉德.巴特尼芙（Irmgard Bartenieff 1900～1981）是一名舞者、编舞者、舞蹈理论家，也是舞动治疗的先驱。
       </span>
       <span style='font-family: mp-quote, -apple-system-font, BlinkMacSystemFont, "Helvetica Neue", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei UI", "Microsoft YaHei", Arial, sans-serif;color: rgb(52, 44, 44);font-size: 14px;'>
        她师从拉班动作分析（简称LMA）的创始人鲁道夫.拉班（﻿Rudolf von Laban 1879—1958）。并
       </span>
       <span style='font-family: mp-quote, -apple-system-font, BlinkMacSystemFont, "Helvetica Neue", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei UI", "Microsoft YaHei", Arial, sans-serif;color: rgb(52, 44, 44);font-size: 14px;'>
        将拉班动作中的身体层面进行了进一步发展，
       </span>
       <strong style='font-family: mp-quote, -apple-system-font, BlinkMacSystemFont, "Helvetica Neue", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei UI", "Microsoft YaHei", Arial, sans-serif;'>
        <span style="font-size: 14px;color: rgb(52, 44, 44);">
         依照生命之初动作发展的自然顺序，发现了身体连接的六个基本模式（呼吸、核心与肢端、头与尾、上下半身、左右半身、身体对侧）
        </span>
       </strong>
       <strong>
        <span style='font-family: mp-quote, -apple-system-font, BlinkMacSystemFont, "Helvetica Neue", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei UI", "Microsoft YaHei", Arial, sans-serif;font-size: 14px;color: rgb(52, 44, 44);'>
         ，并在此基础之上运用解剖学、运动学、身心发展学的知识，提供了一套观察和探索身体和动作的原则和练习，后来被人称之为巴特尼芙基本动作。
        </span>
       </strong>
       <span style='font-family: mp-quote, -apple-system-font, BlinkMacSystemFont, "Helvetica Neue", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei UI", "Microsoft YaHei", Arial, sans-serif;font-size: 14px;color: rgb(52, 44, 44);'>
       </span>
      </p>
      <p style="white-space: normal;">
       <span style="font-size: 14px;color: rgb(52, 44, 44);">
       </span>
      </p>
      <p style="white-space: normal;">
       <span style="font-size: 14px;color: rgb(52, 44, 44);">
        <br/>
       </span>
      </p>
      <p style="white-space: normal;">
       <span style="font-size: 14px;color: rgb(52, 44, 44);">
        巴特尼芙基本动作（BF）是一种基础身体训练（Basic Body Training）的方法，
        <strong>
         它在一个鼓励个人化表达与全身心投入的脉络中，依据有效动作的原则，来探讨和处理身体的模式化连接。
        </strong>
        之所以叫「基本动作」，是因为这些模式和动作是婴幼儿早期动作发展中自然显现出来的，是后期复杂动作的基础。
        <strong>
         而如果一个人现有的模式有所局限，或者想在动作合理性、复杂性、难度方面有更大的扩展和突破、最好的方式是先回到基础的地方，从那里重新开始。
        </strong>
       </span>
      </p>
      <p style="white-space: normal;">
       <span style="font-size: 14px;color: rgb(52, 44, 44);">
        <strong>
         <br/>
        </strong>
       </span>
      </p>

      <p style="white-space: normal;">
       <span style="font-size: 14px;color: rgb(52, 44, 44);">
       </span>
      </p>
      <p style="margin-bottom: 0px;font-size: 16px;letter-spacing: 1px;text-wrap: wrap;">
       <span style="text-decoration: underline;">
        <strong>
         <span style="text-decoration: underline;font-size: 14px;color: rgb(52, 44, 44);">
          *什么是身心学？
         </span>
        </strong>
       </span>
      </p>
      <p style="margin-bottom: 0px;font-size: 16px;letter-spacing: 1px;text-wrap: wrap;">
       <strong>
        <span style="font-size: 14px;color: rgb(52, 44, 44);">
         身心学
        </span>
       </strong>
       <span style="font-size: 14px;color: rgb(52, 44, 44);">
        的概念源自欧美国家，它是
        <strong>
         一门探究身心关系和体悟身体智慧的经验科学，重视内在经验的体会和反省，探索人体觉察、生物功能和外在环境三者间互动关系。
        </strong>
        可以说身心学是源自西方的一种对身体的回归和探索，它不把身体当作一个客体，而是认为身体具有自身的智慧和理性——一种语言之外的理性。身心学认为身体本身是一个“有心性的身体”，甚至相对于头脑来说，身体的智慧更为本源。
       </span>
      </p>
      <p style="margin-bottom: 0px;font-size: 16px;letter-spacing: 1px;text-wrap: wrap;">
       <span style="font-size: 14px;color: rgb(52, 44, 44);">
        <br/>
       </span>
      </p>
      <p style="margin-bottom: 0px;font-size: 16px;letter-spacing: 1px;text-wrap: wrap;">
       <span style="color: rgb(52, 44, 44);font-size: 14px;">
        身心学中有很多不同的流派，起源于不同的线索。譬如亚历山大技术、费登奎斯的动中觉察，拉班舞谱和由此发展而来的巴特尼芙基本动作等等。
       </span>
      </p>

       </span>
       <span style='color: rgb(52, 44, 44);font-size: 14px;font-family: mp-quote, -apple-system-font, BlinkMacSystemFont, "Helvetica Neue", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei UI", "Microsoft YaHei", Arial, sans-serif;'>

        从看上去简单到真正将其运用到身体体验之中，两者间有很大的距离。
       </span>
       <strong style='color: rgb(52, 44, 44);font-size: 14px;font-family: mp-quote, -apple-system-font, BlinkMacSystemFont, "Helvetica Neue", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei UI", "Microsoft YaHei", Arial, sans-serif;'>
        这些基本模式和原则一方面对于太极的练习有极大的参考意义，另一方面太极也正好提供了一个回到基本模式，具身化这些原则的方法。
       </strong>
       <br/>

       <span style="font-size: 14px;color: rgb(52, 44, 44);">
        我练习太极在前，学习巴特尼芙及相关身心学体系在后，
        <strong>
         我感觉太极如同一个容器，可以很自然地融入很多身心学的相关理念
        </strong>
        。太极有形的桩与拳，以及日复一日的练习，恰好是一个体验身心学相关理念并将其具身化的最好框架和途径。而身心学试图用语言来把捉那难以捉摸的“有心性的身体”的微妙之处，这对于太极的深化练习也很有帮助。
