                  <span style="font-size: 14px;">
                   身体像是块很大的版图（Continent），许多的大陆间相互连结但也各自独立。
                  </span>
                 </p>
                 <p style="text-align: left;text-wrap: wrap;">
                  <span style="font-size: 14px;">
                   如果用一句话来介绍「接触即兴」，那就是：
                  </span>
                  <strong>
                   <span style="font-size: 14px;">
                    身体的对话
                   </span>
                   <span style="font-size: 14px;background-color: rgba(1, 0, 0, 0);">

                   </span>
                  </strong>
                  <span style="font-size: 14px;background-color: rgba(1, 0, 0, 0);">
                  </span>
                 </p>
                 <p style="text-align: left;text-wrap: wrap;">
                  <span style="font-size: 14px;">
                   艺术通常与感官有关，音乐对应耳朵，舞蹈对应眼睛，这是对观众而言的。
                  </span>
                 </p>
                 <p style="text-align: left;text-wrap: wrap;">
                  <span style="font-size: 14px;">
                   身处其中的舞者，视觉、听觉、触觉、还有身体对重力的感觉、对时间的感觉、对节奏的感觉、对他者的感觉等等，这些觉知全部
                   <strong>
                    在场
                   </strong>
                   。
                  </span>
                 </p>

                  <span style="font-size: 14px;">
                   对话，就是发生在这里的。
                  </span>
                 </p>
                 <p style="text-align: left;text-wrap: wrap;">
                  <strong>
                   <span style="font-size: 14px;">
                    身体的每一个感官都在独立感知周围世界的同时又在感应着彼此，像是一块块漂浮在海上的岛屿。
                   </span>
                  </strong>
                 </p>
                 <p style="text-align: left;text-wrap: wrap;">
                  <span style="font-size: 14px;">
                   在接触即兴中，岛屿连成一大块陆地。
                  </span>
                 </p>
                 <p style="text-align: left;text-wrap: wrap;">
                  <span style="font-size: 14px;">
                   再借由接触中的身体对话，与其他更远处的大陆接近、连结、碰撞和交换，连成一个更广阔的板块。
