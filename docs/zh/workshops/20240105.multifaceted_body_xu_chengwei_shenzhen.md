           <p style="text-wrap: wrap;">
            你有多久没有好好地看过自己的身体？
           </p>
           <p style="text-wrap: wrap;">
            <br/>
           </p>
           <p style="text-wrap: wrap;">
            许多时候，支撑你我根本的「身体」，却总是被我们繁琐、忙碌的生活所遗忘。
           </p>
           <p style="text-wrap: wrap;">
            <br/>
           </p>
           <p style="text-wrap: wrap;">
            你是否会好奇，一天当中，同一个关节你使用了多少次？你是否会好奇身体是以几种方式协调的支持着你的生活？你又知否，自己的身体能够呈现出多少种不同的面相？
           </p>
           <p style="text-wrap: wrap;">
            <br/>
           </p>
           <p style="text-wrap: wrap;">
            曾几何时，你有真实地面对自己的身体？

        <section powered-by="xiumi.us" style="font-size: 14px;line-height: 1.75;">
         <p style="text-wrap: wrap;">
          「舞蹈像是从天上掉下来的礼物」，从15岁开始学习舞蹈的许程崴，形容自己第一次「
          <strong>
           通过舞蹈感觉到了自己身体的存在」。
          </strong>
          在舞蹈中的每一次翻滚，每一次落地，甚至每一次疼痛，都会让他感受到身体的存在，因此他再未离开过舞蹈。
         </p>
         <p style="text-wrap: wrap;">
          <br/>
         </p>
         <p style="text-wrap: wrap;">
          许程崴于2009年受邀加入古舞团，这是中国台湾一支以接触即兴表演实践为独特道路的舞团，由「亚洲接触即兴教母」古名伸创办。「是接触即兴选择了我」，加入古舞团以后，许程崴成为了团中最年轻和活跃的舞者之一，他形容自己是舞团中的那只「狮子」，每次需要去打破地板上的某些旧模式时，他就会负责先扑上去。风格多变，丰富、大胆、有趣的身体语言，是许程崴身上带有的印记。另一方面，出身于丧葬业家族的底色，曾使他着迷于对生命和死亡议题的探索。
         </p>
         <p style="text-wrap: wrap;">
          <br/>
         </p>
         <p style="text-wrap: wrap;">
          2015年的夏天，「许程崴制作舞团」在中国台湾成立，许程崴透过创作不断探索和挖掘自身对于生命的开发，并以回归身体本质为动作脉络出发，形成其独特刚柔并济的舞蹈美学。
         </p>

         <p style="text-wrap: wrap;">
          <span style="font-size: 14px;">
           2016-2023年间
          </span>
          <span style="font-size: 14px;">
           ，许程崴（阿崴）曾多次往返上海、杭州、南京等城市，向大众传播身体之美和接触即兴舞蹈的有趣之处。
           <strong>
            很多人形容阿崴老师的课堂风格是「大胆」，因为他真诚的认为每个人的身体都有无限的可能。
           </strong>
           在许程崴的课堂中，不会去挑选只有什么样特质的人才能做到什么样的动作，而是带领大家像解密一样，不断地探寻身体的边界。

           <strong>
            每个人遇到任何的问题，然后去解决。有可能是一个「麻烦」的问题，也有可能是一个「困难」的问题，而在这个解决问题的过程中，就是「即兴」的状态。
           </strong>
          </span>
         </p>

             <span style="background-color: rgba(254, 241, 64, 0.99);">
              <strong>
               什么是接触即兴？
              </strong>
             </span>
            </p>
           </section>
          </section>
         </section>
        </section>
        <section powered-by="xiumi.us" style="text-align: left;justify-content: flex-start;display: flex;flex-flow: row;margin-bottom: 10px;">
         <section style="display: inline-block;width: 100%;vertical-align: top;align-self: flex-start;flex: 0 0 auto;border-style: solid;border-width: 1px;border-color: rgb(62, 62, 62);padding: 58px 29px 29px;">
          <section powered-by="xiumi.us" style="text-align: justify;line-height: 1.75;">
           <p style="text-wrap: wrap;">
            <span style="font-size: 14px;">
             「接触即兴」（Contact Improvisation，CI) 属于一种后现代舞蹈，融合了太极、合气道、现代舞以及东方的哲学思维等多种元素，1972年初由美国舞蹈艺术家Steve Paxton与伙伴构想和展现。因其诞生之始便带有
             <strong>
              「打破常规」的后现代性，企图破除传统舞蹈中对于年龄、性别、角色等定义，提倡人人皆可舞，同时在舞蹈中尊重每一位个体独有的身体特色，
             </strong>
             从而逐渐被各种各样的团体学习、发展、融合，并在全球流行开来。
            </span>
           </p>
           <p style="text-wrap: wrap;">
            <span style="font-size: 14px;">
             <br/>
             虽说是舞蹈，但「接触即兴」并不仅追求视觉上的审美，而
             <strong>
              更为关注舞者之间的联系，强调对动作，对自我身体尤其是人与人之间连接的觉知。
             </strong>
             借助重力和身体的物理结构，舞伴们互相给予重量并且接受重量。跟舞蹈相比，它像是一种运动，但和运动相比，它又具有独特的艺术气质。
            </span>
           </p>
           <p style="text-wrap: wrap;">
            <span style="font-size: 14px;">
             <br/>
             在接触即兴的过程中，舞伴们会不断寻找身体共同的框架，回归身体的本能觉察。在平衡和失衡间感受身体的张力。用身体作为杠杆，去承受外部的重量，通过身体的转换和流动，发掘自我身体中不可思议的本能所带来的力量。
            </span>
           </p>
           <p style="text-wrap: wrap;">
            <br/>
           </p>
           <p style="text-wrap: wrap;">
            <span style="font-size: 14px;text-decoration: underline;">
             <strong>
              什么是舞酱？
             </strong>
            </span>
           </p>
           <p style="text-wrap: wrap;">
            <span style="font-size: 14px;">
             舞酱，音译自 Jam，是所有人一起自由跳舞的舞会。与课程或工作坊不同，舞酱没有正式的教学、固定舞步或规则。大家会在一起跳舞，玩耍，练习，或者就是坐在旁边观看，享受当下的一刻。
            </span>
           </p>
