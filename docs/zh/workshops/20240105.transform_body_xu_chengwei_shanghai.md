               <p style="text-wrap: wrap;">
                不知从何时开始，我最喜欢的字就是「变」。
                <strong>
                 「变」，是舞蹈身体的选择，亦是想象力的延伸。变，是变化多端的「变」，是变魔术的「变」，是蜕变的「变」还是善变的「变」？是刻意的改变？还是自然的转变？
                </strong>
                在这一次上海的工作坊中，我希望与大家一起从思考、意识、理解与意义出发并进行延伸，并通过接触即兴来思考什么是「个体」？什么又是「群」的意义。

              <section style="text-align: justify;">
               <p style="text-wrap: wrap;">
                <span style="font-size: 14px;">
                 「接触即兴」（Contact Improvisation，CI) 属于一种后现代舞蹈，融合了太极、合气道、现代舞以及东方的哲学思维等多种元素，1972年初由美国舞蹈艺术家Steve Paxton与伙伴构想和展现。因其诞生之始便带有
                 <strong>
                  「打破常规」的后现代性，企图破除传统舞蹈中对于年龄、性别、角色等定义，提倡人人皆可舞，同时在舞蹈中尊重每一位个体独有的身体特色，
                 </strong>
                 从而逐渐被各种各样的团体学习、发展、融合，并在全球流行开来。
                </span>
               </p>
               <p style="text-wrap: wrap;">
                <span style="font-size: 14px;">
                 <br/>
                 虽说是舞蹈，但「接触即兴」并不仅追求视觉上的审美，而
                 <strong>
                  更为关注舞者之间的联系，强调对动作，对自我身体尤其是人与人之间连接的觉知。
                 </strong>
                 借助重力和身体的物理结构，舞伴们互相给予重量并且接受重量。跟舞蹈相比，它像是一种运动，但和运动相比，它又具有独特的艺术气质。
                </span>
               </p>
               <p style="text-wrap: wrap;">
                <span style="font-size: 14px;">
                 <br/>
                 在接触即兴的过程中，舞伴们会不断寻找身体共同的框架，回归身体的本能觉察。在平衡和失衡间感受身体的张力。用身体作为杠杆，去承受外部的重量，通过身体的转换和流动，发掘自我身体中不可思议的本能所带来的力量。
                </span>
               </p>
               <p style="text-wrap: wrap;">
                <br/>
               </p>
               <p style="text-wrap: wrap;">
                <strong>
                 <span style="font-size: 14px;">
                  什么是舞酱？
                 </span>
                </strong>
               </p>
               <p style="text-wrap: wrap;">
                <span style="font-size: 14px;">
                 舞酱，音译自 Jam，是所有人一起自由跳舞的舞会。与课程或工作坊不同，舞酱没有正式的教学、固定舞步或规则。大家会在一起跳舞，玩耍，练习，或者就是坐在旁边观看，享受当下的一刻。
                </span>
               </p>

        <section powered-by="xiumi.us" style="font-size: 14px;line-height: 1.75;">
         <p style="text-wrap: wrap;">
          2024年的春天，许程崴将再次为上海带来主题为「变·身」的为期3日的接触即兴舞蹈工作坊。
          <strong>
           「变」是入口，也是我们尚在「活着」的铁证，世界上唯一不变的事情就是每一件事情都在不断地改变。
          </strong>
         </p>
         <p style="text-wrap: wrap;">
          <br/>
         </p>
         <p style="text-wrap: wrap;">
          在接触即兴工作坊的练习过程中，我们将从
          <strong>
           「感受」直达动作的「形状」，回归对身体结构本质的理解，体会并掌握重心的转换
          </strong>
          。通过内在与外在的合作，了解身体是为「意」的变化，成为「意」的固体形态。稳定的「意」与善变的「意」都需要时间的理解和琢磨，
          <strong>
           在「变——身」的议题中，老师将带入「承接变化」的联系，身和意随时变化，为流动中的身体寻找机会
          </strong>
          。
          <span style="letter-spacing: 0.034em;">
           犹如太极使身体达成流水不腐，传递顺利，自然可达成「吞天之气、接地之力、寿人以柔」。
          </span>
         </p>
